# KESO PLAY オリジナルBGM（音源配置）
配置するファイル：
- `music/assets/mou-isshu.mp3` — 『もう一周』、サウンドボード付きマスター版
- `music/assets/genkai-rhapsody.mp3` — 『限界集落狂詩曲』、2分24秒の採用版

現状のPRはプレイヤーUI・端末設定を追加するもの。バイナリ音源はチャット添付からGitHubへ直接転送できず、別途上記パスへ配置が必要。
未配置でもゲームは正常に動く。プレイヤーでは各自の端末からファイルを読み込める。ファイルは利用可能な端末ではIndexedDBに保存され、KP/D1は一切消費しない。
音源追加時は `music/player.js` のtracks配列に曲を追加する。
**Discord通話保護**：初期停止、15%音量、ユーザー操作後に再生。画面が非表示になったら停止。
**利用権**：Suno有料プランで本人が生成した音源として管理し、配信前に権利と公開範囲を確認する。
