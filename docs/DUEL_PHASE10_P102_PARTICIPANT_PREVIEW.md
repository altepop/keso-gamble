# P10.2 認証済み参加者プレビューAPI（部分実装・安全境界）
- 新しい`GET /api/kp/duels/spectator-preview?id=<UUID>&version=<optional integer>`は**既存KPセッション認証後**の経路に限り、既存の試合参加者本人だけに閲覧を許可する。
- ギルド越境・第三者の試合は既存のroom()スコープ参照で拒否。取得した秘密付きDB行はP10.1の許可リストに射影してから返し、private_handや非公開カードは返さない。
- 一致するversionはno_change、それ以外はスナップショット。クライアントは自動更新しないため、**同期方式polling/SSE/DOは未選定**。
- このAPIは**参加者プレビュー**であり、第三者観戦APIではない。第三者同意/公開ポリシー/観戦者認可/観戦入口/Discord Activityライブ表示は未実装。これはP10.2スコープ縮小ではなく、5項目が未承認のための安全ゲートである。
