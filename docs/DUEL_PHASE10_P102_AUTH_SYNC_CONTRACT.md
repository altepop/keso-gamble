# P10.2 認可・同期契約 — 部分実装

**スコープフラグ**：P10.2全体の完成ではない。今回の追加は、APIの接続前に必要な拒否優先の認可判定と更新番号比較という、同期方式に依存しない純粋関数のみである。Discord画面への組込、実際の認証済みエンドポイント、ライブの配信方式、観戦同意UIは未実装であり、承認後に必ず行う。これらをロードマップAから削除・縮小しない。

## 契約
- 呼出元が認証された利用者とギルドを確認し、明示的な承認済み閲覧者リストを与えた場合にのみ閲覧を認める。入力が不足する場合、別ギルド、未承認の閲覧者は拒否する。
- **閲覧者リストを自動生成しない**。現在は全ユーザー閲覧可能なAPIを作らない。
- 版番号一致はno_change、それ以外はP10.1の公開スナップショットを返す。polling/SSE/DOのいずれかを選択したわけではない。
- 将来、認可を行うサーバー側境界でのみ利用し、クライアント提供の承認リストを信用しない。
