# 等しいbot：実AIによる牌譜のひと言

## 今までの投稿を守る

「アカンbotが速報 → 等しいbotが牌譜投稿」の順序と、順位・KP・主な和了・メンバー別成績/煽り・最後の引用文は従来どおり。
等しいbotが牌譜中の実際の打牌を見て、関西弁の一人称で褒めたり軽く指摘したりする短いコメントだけを追加する。
**プレイヤー向けの本文には解析モデル名を出さない。**
Discordの1900字に余裕がない場合は新コメントだけを省略して旧投稿を維持する。

表示イメージ（架空の対局であり実解析の引用ではない）：

> 「けそ、東1局の4巡目の6pなあ。僕はここで3p切りますけどねぇ〜。ちょっと惜しい気がしますわ」

> 「小林、東3局の9巡目の東ねぇ。僕もそれ切りますわ。ええ感じやと思いますよぉ〜」

実在人物の発言の引用ではなく、botの創作コメントである。

## 完全な解析経路

1. 従来のGitHub Actionsで雀魂の牌譜を1回取得し、詳細なprotobufイベントを復元。
2. `src/mahjong-c3-cases.ts` が各席の**打牌直前**の場面をMJAIの履歴へ変換。本人の手牌/ツモのみ渡し、他者の配牌/隠れたツモ/未来の牌は伏せる。
3. `scripts/c3-vendor/` に元M-LEAGUE Managerの小さな推論用JSをユーザー許可のもと移植。モデルとWASMの**大きなバイナリはGitに追加せず**、`scripts/mahjong-c3-download.mjs` がユーザー管理の [M-LEAGUE Manager配布サイト](https://m-league-manager.onrender.com/assets/c3/manifest.json) から取得。サイズ・SHA256検証後、GitHub Actionsのキャッシュに保存。原配布物のMIT/AGPLライセンス、対応ソースへの案内は `scripts/c3-vendor/README.md` に記載。
4. `scripts/mahjong-c3-infer.mjs` が元モデルのONNXと観測WASMをActions Node24で**実推論**。モデルが合法な打牌を返した局面について、本人の実打牌と比較。
5. 署名付きの従来サマリーに、最多4件の「局・本人巡目・実打牌・モデルの打牌」を任意添付。 `src/mahjong-paipu.ts` が等しいbotのコメントを最多2件表示。推奨一致なら自然に称賛、不一致なら「僕なら〜」と指摘。単なる不一致を確定的な失着と呼ばない。
6. 解析に失敗しても、既存の牌譜取得・KP精算・投稿は続行。D1にモデルや詳細牌譜を保存せず、既存のクエリ回数を増やさない。

**現時点での解析対象：四麻の無鳴き、立直前、槓前の確実に復元できる一部の局面。** 副露や立直が発生した後は無理に推測しない。三麻と全打牌レビューは別途対応が必要。実局面の強さの数値評価はしない。

## CIと検証

- KESO PLAYの公開GitHub Actionsで [実モデル検証run #42354964605](https://github.com/altepop/keso-gamble/actions/runs/42354964605) が成功：オリジナルモデルの取得と全配布SHA256確認、WASM/ONNXの初期化と実推論、キャッシュ保存。
- [実モデル+架空の合法牌譜の通し検証run #42355161009](https://github.com/altepop/keso-gamble/actions/runs/42355161009) も成功：配牌・ツモ・打牌からMJAI観測を復元し、元モデルによる推論から比較結果まで生成。
- いずれも公開リポジトリの標準GitHub-hosted runner上の実行であり、非公開リポジトリのActions無料枠には影響しない。
- 実際の雀魂サーバーから取得した対局での再現・検証は別途必要。**架空の牌譜で通っただけで、本番自動批評が開始されたとは主張しない。**

## 有効化とロールバック

モデル取得に非公開リポジトリ用トークンは**不要**。モデルを公開するのではなく既存の公開配信物を使う。不要になった非公開M-LEAGUE Manager側の実験PR #173は閉じた。

**PRのマージ後は既存の牌譜取得ワークフローで自動的に解析を試みる。** 追加のSecretやVariable設定は不要。問題が発生した場合は、GitHub `altepop/keso-gamble` の Repository Variables に `MAHJONG_EQUAL_REVIEW_ENABLED=false` を設定すると、モデルのダウンロード・推論を直ちに止めて旧来の等しいbotだけに戻せる。実行のたびの外部モデル取得はキャッシュを使い、キューが0件ならモデルを読み込まない。

**追加のSecretやD1 migrationは不要**。実行前の独立検証には GitHub Actions の `Mahjong paipu fetch` の `c3_probe=true` を使う（雀魂ログイン、Discord、KP、D1操作は行わない）。

## 未完成の範囲

- リアルな雀魂の任意の局面（特に鳴き・立直・槓・追っかけリーチ・場面ごとの打点差）を網羅できたわけではない。
- 同じ選択だったことは推奨との一致であり、「プロ級」「絶対正解」などの能力評価ではない。
- 厳密な手牌の受け入れ・現物・危険度などの計算まで移植したわけではないため、根拠のない具体的理由を作文しない。
- 追加したレビュー部分の安全性だけで、既存KP・D1の正確性を新たに証明したわけではない。従来のテストが守る領域を維持する。


## 開発中の三麻と任意解析の障害分離（第1段階）

`feat/mahjong-review-sanma` / Draft PR #377 は未完成の開発版。詳しい調査・制限・自己採点・再開手順は [開発引き継ぎ](MAHJONG_REVIEW_DEVELOPMENT_HANDOFF.md) を参照。

- 三麻は四麻モデルへ渡さず、独立した牌構成で向聴数/受け入れを計算する。現状は序盤門前など限定した形の比較だけで、和了打点・守備・着順・北抜き選択の全面解析ではない。
- 新しい `MAHJONG_SANMA_REVIEW_ENABLED` は未設定/falseで無効。実牌譜照合が済むまで有効化しない。従来の四麻の既定設定を変える必要はない。
- 任意解析はkill可能なworker内で遅延起動する。四麻の有効な局面がなければモデルを取得/初期化しない。既存のActionsキャッシュを再利用する。
- モデル取得・初期化・推論が失敗/停滞しても、45秒/回・合計90秒/バッチで打ち切って牌譜/KPフローを続行する。
- 四麻の推奨打牌は、観測器の合法maskと復元手牌の両方で確認する。既存の四麻の鳴き/立直/槓後の除外はまだ解除していない。
