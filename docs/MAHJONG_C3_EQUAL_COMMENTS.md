# 等しいbot：一打を関西弁で検討する仕組み

## そのまま残すもの

速報は従来どおりアカンbot、牌譜投稿は従来どおり等しいbot。
順位・KP・主な和了・メンバー別データ/煽り・最後の引用文は変更しない。
Discord の1900文字枠が足りない場合は**新しいコメントを省略**する。
プレイヤー向けの文面では解析エンジン名を出さない。

表示例（架空の牌譜。実対局の検討結果ではない）：

- 「けそ、東1局の4巡目の6pなあ。僕はここで3p切りますけどねぇ〜。ちょっと惜しい気がしますわ」
- 「小林、東3局の9巡目の東ねぇ。いや、僕もそれ切りますわ。これはええと思いますよぉ〜」

創作のbot文面であり、実在人物の発言を引用したものではない。

## 実接続

対象ソース：

- `scripts/mahjong-paipu.mjs`：既存の雀魂ログイン・牌譜取得を一度だけ行う。
- `src/mahjong-c3-cases.ts`：元の牌譜の配牌・ツモ・打牌から、**打牌を切る直前**のMJAI観測を再現。C3には本人の手牌だけを渡し、他家の配牌・隠れたツモ、未来の情報を「?」に置換。
- `scripts/mahjong-c3-infer.mjs`：別の非公開M-LEAGUE Managerから読み取った元ONNXモデル＋Mortal WASM観測器を、GitHub ActionsのNodeで1回だけ初期化して実推論。
- `src/mahjong-paipu.ts`：任意の検討結果を署名済みサマリーとともに取り込み、検証済みの局・巡目・自分の一打・提案牌だけを使って関西弁の短いコメントを生成。
- `.github/workflows/mahjong-paipu.yml`：キューがあるときだけ、秘密の読み取り専用トークンでM-LEAGUE Managerからモデル資材を一時的に取得する。

現在の安全な解析対象は**四麻・東南/東風・副露/リーチ/槓のない局面**。局面の曖昧さを減らすため、立直や副露などが起きた局は、その地点以降を解析対象から除外する。親の配牌に14枚あることに対応し、最初の親の捨て牌自体は検討しない。三麻は対象外。

エンジンが打牌を選んだ場合だけ、元の同じ局面での実打牌と比較する。立直、槓、ロン、ツモ和了などを打牌の推奨に変換しない。Q値を失着率/放銃率/期待打点と表示せず、異なる選択だけで確定的な「失着」とは言わない。AIと一致した一打は自然に褒める。1件ずつの批評と称賛を優先し、最大2コメント。

## 運用設定（本番ONに必要）

GitHub `altepop/keso-gamble` の設定で：

1. **Actions secret** `M_LEAGUE_C3_TOKEN`：非公開 `altepop/m-league-manager` の **Contents: Read-only** だけを許した fine-grained token。公開リポジトリのソースやDiscordへは絶対に表示しない。
2. **Actions variable** `MAHJONG_EQUAL_REVIEW_ENABLED=true`：コード/モデルのCIと実牌譜の試行が成功した後にのみ設定する。

実モデルを本番で有効化する前に、**`MAHJONG_EQUAL_REVIEW_ENABLED` は設定しないまま**、GitHub の Actions → `Mahjong paipu fetch` → `Run workflow` → `c3_probe=true` を手動実行する。これはモデルを実際に読み込んで1回ONNX推論するだけで、雀魂ログイン・Discord・D1・KPには触れない。読み取り秘密値がないと明示エラーにする。

両方が揃わない場合はモデルを取得せず、既存の等しいbotの投稿とKP精算だけを実行する。取得や推論に失敗した場合も、結果を捏造せず旧機能を維持する。

GitHub Actionsのjobを安全に試すには、まずprivate repoの [Node実推論スモークPR #173](https://github.com/altepop/m-league-manager/pull/173) が成功することを確認する。その後、四麻の実牌譜で牌・巡目・匿名化・推論結果を確認する。

## 現在の検証と留保

- 数値の出所：元C3ネットワークはM-LEAGUE Managerで以前にブラウザ検証済み。ただし**GitHub Actions/Nodeで同一モデルが動くかは別検証**である。
- 元モデル・観測WASM等は合計約57.4MB。公開KESO PLAYのソース管理・Cloudflare D1へは移植せず、Actions runner上でのみ読み取る。
- C3の重みはMIT、Mortal観測器由来コードはAGPL-3.0-or-laterに従う。非公開モデルを公開ソースへ誤って流出させない。
- モデル資材・本人以外の隠し牌・長い生牌譜をWorkerに送らない。Workerには最大4件の選択結果のみ追加される。
- アカンbot速報、KP、旧煽り、引用文、既存D1データには追加の読み取りはなく、元サマリーへ小さな任意フィールドが増えるだけである。
- 最新CI/実牌譜/Nodeモデル実行を経ず、実際に全自動運用が開始したとは報告しない。

## 次に拡張できる部分

- 副露、槓、立直後の正確なMJAI再現を加え、全打牌検討へ拡大。
- 攻守/向聴/受け入れ/打点を実牌譜から照合し、検証できる具体的な理由だけでコメントする。
- 本人同意・情報管理の範囲で三麻に対応（四麻専用モデルを三麻へ無理に使わない）。
