# P10.3 実音・Discord通話経路ゲート（PROPOSED）
Phase 10 P10.3の**部分実装**である。開始・手番交替・終了の公開確定イベントを、将来の音声経路に渡す前に明示的な許可で判定する純粋契約を追加する。

実音の再生、Discord通話ボットへの送信、音声チャンネル接続、観戦者への通知は**今回実装・有効化しない**。これはユーザー未承認の演出音声許可と観戦公開ポリシーを勝手に決めないためのゲートであり、P10.3の最終スコープから削除するものではない。

将来の接続は、サーバーで検証した公開権限、音声ポリシーの明示承認、閲覧者・通話チャンネル双方のopt-in、無音設定、アクセシビリティ、重複抑止、失敗時の非送信を必須条件とする。今回追加した判定関数をクライアント自身が申告したフラグで通過させるのは禁止である。

5つの未承認事項はすべて**PROPOSED**：観戦公開ポリシー、同期方式、大会規模・方式、演出音声、運営者ロール。P10.2実ライブ観戦・P10.3実音声・P10.4大会運営は未完成である。Phase 9報酬ポリシーINSERTなし、報酬未有効化。ロードマップAを維持する。
