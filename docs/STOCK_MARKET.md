# 本番の株

2026-10-28。Discordサーバーごとに一つの相場を持ちます。端末内デモは従来どおり独立しています。

## 共通相場

Workerが5分ごとに価格を更新します。全員が同じ価格で売買し、売買それぞれの1%手数料は従来どおりです。更新時刻と約定が重なった注文は再見積もりし、古い価格では約定しません。同じ操作IDの再送は最初の結果を返します。

乱数はサーバーの暗号学的乱数です。通常の値動きはKESOが±0.6%、RISOが±1%、YUYAが±2%、YANOが±0.5%の範囲。ニュース効果を加算し、株価は20〜10,000,000 KPの範囲に収めます。毎回の上昇や利益を保証する仕組みではありません。

チャートは実際に保存した共通相場の履歴を使います。未観測の価格や出来高、板情報は作りません。停止中の架空の値動きも補いません。

## 朝9時の配当

日本時間9時の時点で24時間以上続けて保有している株が対象です。対象株の評価額の1%を整数に切り捨て、全銘柄合計で1人1日最大500 KPを口座に入れます。当日の評価価格は一度保存したものを使います。

買い増し分は買い増した時刻から24時間待ちます。売却は古い購入分から減らすため、売って買い直しても元の保有期間は復活しません。配当処理の再実行や同時実行で二重支給しません。入金と支給記録は同じトランザクションです。

毎分の監視と口座アクセスで処理します。過去の日の配当は遡って支給しません。移行した保有株も移行時刻から24時間が始まり、それ以前の保有期間は推定しません。

## 株主優待

24時間以上保有した分の現在評価額に応じて、指名指令と超高級品の購入額を割り引きます。

| 対象株の評価額 | 割引 |
| --- | --- |
| 10,000 KP未満 | なし |
| 10,000 KP以上 | 3% |
| 50,000 KP以上 | 5% |

割引額は端数切り捨てで、1回の購入につき最大2,000 KPです。売却や価格変動で条件を下回ると優待率も変わります。クライアントが送った割引率は使用しません。馬券やカジノ、株の買い付けには適用しません。既存の購入回数制限と借KP中の購入制限は維持します。

## 実績とニュース

外部の実在企業のニュースではなく、サーバーで確定したゲームの記録を使います。投稿本文やブラウザーの自己申告は根拠にしません。

| 銘柄 | 材料 | 価格効果 |
| --- | --- | --- |
| KESO | VALORANTの勝敗 | 勝利+0.4%、敗戦−0.3% |
| RISO | QUIZの確定プレイ | +0.15% |
| YUYA | 競馬の大きな精算 | 5,000 KP以上の純増+0.5%、純減−0.4% |
| YANO | 5分間に5件以上の株売買 | +0.15% |
| MITU ミツノアジ証券 | 前回の更新から今回までに、誰かがKPを失った回数 − 得た回数 | 1回につき+0.2%（得た回数が多ければ下がる） |
| OKBR おこぼれ商事 | MITU の逆 | 1回につき−0.2%（得た回数が多ければ上がる） |
| KOJI・ISHI・VDK・KOBE・NGYA・HORI | 架空の会社のニュース（更新ごとに2〜4%の確率） | KOJI ±2.5%、ISHI ±1.8%、VDK ±0.8%、KOBE ±1.5%、NGYA ±1%、HORI ±1.5% |

MITU・OKBR は金額ではなく回数で動きます。数えるのは、VALORANTの勝ち（入金）と負け（引き落とし）、ユナイト・雀魂の精算、カジノ1回ごとの勝ち負け（チンチロ・ブラックジャック・ルーレット）、競馬とMリーグの的中・外れ1枚ごとです。QUIZ・通話・配当のように増えるだけのもの、購入、返金、テスト用の入金は数えません。1日の上限は他の銘柄より広く8%（KOJIは6%）です。

架空の会社（小路宇宙開発・石原製薬・VDK運輸・神戸鉱山・名古屋電力・堀建設。矢野ファイナンスと同じくメンバーの名前から）は実在しません。ニュースもサーバーの乱数で作る架空のものです。通常の値動きは KOJI ±3%、ISHI ±1.2%、VDK ±0.3%、KOBE ±0.8%、NGYA ±0.5%、HORI ±1%、MITU・OKBR ±0.4% の範囲です。

新しい銘柄は上場価格（MITU・OKBR 1,000、KOJI 300、ISHI 640、VDK 950、KOBE 1,450、NGYA 1,100、HORI 820 KP）から始まります。以前の口座や相場はそのままで、新銘柄は保有0株として扱います。古いチャートの記録には新銘柄の価格がないため、新銘柄のチャートは上場後から表示します。

同じ記録は一度だけ反映します。ニュース効果は銘柄ごとに1更新で合計絶対値2.5%まで、朝9時区切りの1日で3%まで。売買件数による効果はそのうち1日0.3%までです。上限で反映されなかった分を翌日に繰り越しません。導入前の記録は対象外です。

稼ぎchへの急騰・急落のお知らせは前回比3%以上が対象で、同じ銘柄は30分以上空け、サーバー全体で1日最大8件に制限します。既存の投稿待ちキューを使い、勝手なメンションは付けません。

公開相場APIは価格・時刻・銘柄別ニュースだけを返し、個人のDiscord ID、元イベントのID、保有数、配当履歴を公開しません。本人の配当履歴は認証済み口座にだけ返します。

## 以前の株の移行

以前の相場での現在評価額を計算して、同額の共通相場の株に換算します。整数株に換算できない端数はKPへ戻します。銘柄ごとに「移行前評価額 = 移行後評価額 + 端数返金」を守るため、株数は変わる場合があります。

保有数の更新、端数返金、購入ロット、移行済みの記録は一括で確定します。失敗時は全体を取り消し、再実行で二度返金しません。既存の口座や試合報酬、通話、Discord認証は維持します。
