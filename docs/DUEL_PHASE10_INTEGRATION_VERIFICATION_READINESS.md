# Phase 10 統合・検証準備（P10.5/P10.6 候補、ロードマップAを変更しない）

この文書のP10.5/P10.6という呼称は、ユーザーが示した「統合準備・検証準備」という仮の分類である。**ロードマップAへのフェーズ追加・構成変更・実装範囲の縮小ではない**。

## 事前に実行できる検証
- P10.1/10.2：非公開情報の公開DTOへの混入防止、同一ギルドかつ明示許可された閲覧者のみアクセス、版番号の一致・逆行防止。
- P10.3：確定状態だけからテキストキューを作成、音声許可なし・公開許可なし・同意なし・ミュート時は必ず送信拒否。
- P10.4：試算ブラケットの人数重複を禁止、大会規模・運営者権限の未承認時は公開不可。
- Node純粋関数の統合回帰テストを追加するが、実Discord通話・大会開催・D1保存・外部公開を試行しない。

## 承認後の統合検証ゲート（未実行）
1. 公開ポリシー（PROPOSED）：双方同意と撤回、ギルド越境、リンク漏洩、試合終了後の情報保護。
2. 同期方式（PROPOSED）：リアルタイム遅延・再接続・重複抑止・D1予算・チャンネル切断。
3. 大会規模方式（PROPOSED）：確定参加者数・BYE・辞退・試合確定・二重開催・結果監査。
4. 演出音声許可（PROPOSED）：オプトイン・無音・音量制限・権利確認・実Discord通話への接続。
5. 運営者ロール（PROPOSED）：付与・停止・裁定・緊急停止・監査証跡。
