# KESO COACH 「今日」2件固定仕様（2026-11-22承認）

## 表示ルール
- 本日のアップ：1件。本格的で具体的な操作手順を示す。簡易ボットだけの低難度メニューは禁止。
- 本日の座学：1件。マップ・エリア・状況を明示した、根拠を確認できる具体的な知識テーマ。
- 合計2件を超える推奨、候補カード列挙、複数の今日のおすすめは表示しない。詳細データ、設定、通知、取得状況は別の画面へ。
- 強み・弱点は根拠を明示して短く提示。対象マップ・エージェントを恒久的に2マップ／1体へ狭めない。過去に扱った対象を考慮して日次ローテーションする。
- コンペ→試合データ取得→フィードバック→次回練習への循環が一画面で分かること。
- 正式プロトタイプ到着までメイン画面は変更しない。この文書はUI/データの受け皿の契約であり、公開内容や正解を確定するものではない。

## 座学カードの受入データ契約
```ts
type TodayStudy = {
  theme: string;                // 必須：マップ・エリア・状況を特定するテーマ
  reason: string;               // 必須：本人の実測データに基づく選定理由／「まだ分かりません」
  keyPoints: string[];          // 正しい知識がMuse側から提供された時だけ1〜3件
  sourceUrl: string | null;     // 確認済みの一次資料などのリンク。未確定ならnull
  sourceLabel: string | null;   // 表示用の情報源名。未確定ならnull
  sourceStatus: 'verified' | 'unconfigured';
  map: string | null;
  area: string | null;
  agentScope: string[];         // 特定エージェントを固定する目的ではない
  evidenceStatus: 'measured' | 'insufficient';
};
```

- `sourceStatus='verified'` は検証済みhttpsリンクがある場合だけ許可。未設定の場合は `sourceUrl=null` とし、UIは「情報源：未設定」を表示。架空のURL、推定の定点やクロス位置を生成しない。
- 未提供の要点は「要点：情報源の確認待ち」と表示する。曖昧な位置を「正解」と断言しない。
- 本人の戦績だけから戦術知識が不足していると断定しない。実測根拠が不足する場合は「まだ分かりません」と明示する。
- 他人の生データ、PUUID、座標、個人名をカードに入れない。
- アップは操作ステップ、負荷（難易度・量）、成功判定、次戦で試す動作を含む。座学とアップは別のカードで同時に表示する。
- 日付更新・2アカウント統合のときも、本人につきアップ1件＋座学1件を維持する。
- 初期カードの内容を正式プロトタイプとMuse提供の情報源に合わせて確定する。現段階では固定の戦術正解データを登録しない。

## 受入テストの要点
1. 今日のカードがアップ1件、座学1件、合計2件である。
2. 未検証の情報源はリンクを作らず、未設定と表示する。
3. 本人データなしは根拠を捏造せず「まだ分かりません」と表示する。
4. 既存のマップ・エージェントプールを狭めず、日付・本人の履歴に応じて選択が変わる。
5. 375px幅で過剰な縦スクロールや表を強制しない。
6. 実装は新しいプロトタイプ受領後に行い、認証・同意・CAS・Discord通知設定を変更しない。
