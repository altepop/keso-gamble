# P10.2 観戦画面の部分実装（PROPOSEDゲート維持）

**スコープ明示：P10.2の画面描画ロジックのみ**。実際のライブ観戦機能完成とは扱わない。既存ロードマップAに含まれる観戦・通話演出・大会運営はすべて維持する。

- P10.1の安全な公開スナップショットだけを受け取り、ネットワークなしの読み取り専用HTMLへ変換する。
- 6種目の画面を識別し、オセロ・五目並べ・四目並べは公開盤面、Hit & Blowは公開済み履歴、ブラフダイスは公開宣言、ポーカーは秘密保護のため待機表示を用意する。
- 不正なHTML・秘密情報の漏えいをテストする。
- 観戦API、参加者同意、観戦者権限、ライブ同期方式、公開URL、試合操作、音声、大会権限は**実装しない**。未承認事項を既成事実化しないための一時的な境界であり、最終スコープを縮小しない。

## 未承認・PROPOSEDの5ゲート
1. 観戦公開ポリシー：同意者・閲覧対象・終了後公開可否。
2. 同期方式：polling / SSE / Durable Objects の選択と使用量。
3. 大会規模・方式：ブラケットと人数の設計。
4. 演出音声の許可：同意・無音・アクセシビリティ。
5. 運営者ロール：大会設定・停止・裁定・監査の権限。
