- ゲーム・アプリ内での使用が認められているフリーBGMを採用。作品名と作者とCC BY 4.0をここ、およびゲーム内の音量パネルに明示。出典のリンクとライセンスは削除しない。
- 現時点では作者の公開MP3をHTTPS経由で**明示的にBGMをオンにしたときだけストリーミング**する。ローカルへコピーしない。このためオリジン側のホットリンク制限や通信環境で再生不能になる可能性がある。配信条件・音源ファイルの再利用許諾を再確認し、必要ならライセンスを守りながら自前ホストへ切り替えること。
- BGMは初期オフ。音量パネルの「BGMをオン」に触れた時だけ再生する。画面を離れたり効果音全体をオフにすると停止する。Discord通話の音を優先し、初期20%×最大音量25%=**実効5%**。
- BGM/効果音/実況ボイスは3本の個別音量。各ユーザーのlocalStorageにのみ保存し、D1への追加負荷はない。
- 既存の競馬／スロットの原作成音源（Piperのスタジオレンダリング、一部オーナー録音）は引き続き既存の `scripts/audio/README.md` を参照する。本変更では新しい人声のスタジオ収録は行っていない。
- 新曲を採用する場合は**該当曲の発表時期のライセンス**と、BGM音源のホットリンク規約を改めて確認すること。
