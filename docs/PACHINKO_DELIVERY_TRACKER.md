## 1. 進捗管理規則

各フェーズは1件以上の独立PRに分割してよいが、1PR=1分割。実装の進捗はマージ・配備・実行検証と区別する。計画、コード閲覧、仮説、テスト準備だけで完了扱いにしない。下記のチェックは実際の成果と証跡を確認した時にのみ更新する。要件変更・優先順位変更・本番有効化は承認と理由を記録する。

状態: NOT_STARTED / DESIGN / DRAFT_PR / CI_PASS / MERGED / DEPLOYED / VERIFIED / BLOCKED。VERIFIED は当該分割の受入条件を満たしたことを意味し、全体完成を意味しない。
