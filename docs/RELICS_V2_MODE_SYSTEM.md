# 遺物Ver.2：モード特化・98種・召喚Lvごとの全排出率

## 開発方針

- **通常200KP/回、1・10・100・1,000連**。値引きなし。いままで同様、超越の確定天井・低レア合成による超越確定はない。
- **通常遺物98種類**＝14モード × 7レアリティ。各アイテムが固有名と「そのモードだけで発動する」スキルを持つ。共通ガチャにユナイト遺物は排出されない。
- 対象14モード：コンペ、アンレ、スイフト、スパイクラッシュ、チームデスマッチ、エスカレーション、デスマッチ、スカーミッシュ、競馬、カジノ、株、Mリーグ、VCT QUIZ、通話。
- 通常アイテムは他モード・Steam・ユナイト限定を入手条件にしない。**ユナイト遺物と合わせるべきレシピや推奨装備は今後も作らない**。
- Steamおよびユナイト限定遺物の入手条件と単体戦力は維持。KESO LOOP限定遺物は追加しない。
- 既存の通常21種はID・所持数・装備枠を変更せず、対応する新規モード別名称・説明・能力へ更新（最初の3モードに割当）。元の投資を失わせない。

- Lvは累計200回で+1。Lv10まで1,800回、360,000KPが必要。
- 中間Lv2〜9はLv1→Lv10の票数を線形補間、各Lvで正確に100%になるよう一般を残差補正する。実装の正確な値を遺物画面の排出率表に表示。
- Lv10の**一般0%**、希少以上の合計96.000%。伝説以上は66.000%。超越はLv10でも1万分の1。
- 全レアに14種類の異なるモード特化遺物を収録。各レア内では各種類が等確率（1/14）。
- 200KPガチャを1,000連しても、D1への書込は従来どおり単一の原子的KP操作1件。アイテムごとの個別のDB行・定期タスクは作らない。

## 固有能力のしくみ

各レアでスキル発動条件が変化する。遺物名・対応モード・スキル名・条件・倍率・単独上限を固有データとして設定する。スキルは**装備中**かつ対象モードの検証済み支給（または同一トランザクション内の取引）でのみ有効。

- 一般「小さな追い風」：対象額がプラスのとき1%・5KPまで。
- 上質「窮地の報せ」：モード別の低額しきい値以下で4%・14KPまで。
- 希少「攻勢の鐘」：モード別の低額しきい値以上で4%・22KPまで。
- 伝説「大勝の刻印」：モード別の高額しきい値以上で6%・32KPまで。
- 神話「爆発する運命」：モード別の低額しきい値以上で7%・42KPまで。
- 古代「熟達の証明」：勝利／対象の精算で9%・55KPまで。
- 超越「覇者の領域」：勝利／対象の精算で15%・80KPまで。

重複は所持数量の2のべき乗（2、4、8…）ごとに通常遺物の戦力+5（最大+60）、さらに該当スキルの計算倍率に最大+5ポイントを加算する。**高レアを1つ引く快感と、低レアを何度も育てる楽しみの両方**を持たせる。ただしスキル倍率自体は合算上限内で止まる。

### 実際の適用先

- 検証済みVALORANT試合（コンペ・アンレ・スイフト・スパイク・チーデス・エスカ・デスマ）：新規確定の正の報酬に適用。試合1件につき装備4枠の追加額は合計**80KPかつ対象報酬の15%以下**。
- スカーミッシュ：サーバー確認済みの5連勝の払出し、および確定した途中受取のみ。保留ポットの表示・勝敗自体は変更しない。
- 競馬・Mリーグ：新規馬券・予想購入時の微小な支出還元と、公式結果に基づく正の純精算時の還元。レース結果やオッズは変更しない。
- カジノ：ゲーム確定時のプラスの差額に対する微小追加報酬。抽選・確率・ディーラーのロジックを変更しない。
- 株：購入時に小さく還元。**売却時の還元はしない**（自己売買の往復による無制限稼ぎを禁止）。
- 競馬・Mリーグ・カジノ・株の取引系は、装備枠合計で対象額の最大**1%**かつ、全対象取引合算**1日120KP（UTC日付）**まで。状態更新と同一原子操作でカウントする。
- VCT QUIZ：署名済みの新規クイズ完走時だけ付与。
- 通話：1枠5分が証明されたうえで、**4枠ごと（20分に1回）**のみ特化ボーナスを判定し、D1のレコード数を抑える。
- 既に精算済みの結果に遡及して支給しない。重複イベントID、署名リプレイ、装備の付け替えによる再請求も不可。

## 不正対策・経済

- ブラウザーの `mode` や `reward` 自己申告は信用しない。モードと金額は既存のサーバー検証・署名済みイベント・確定取引からのみ導出する。
- 各スキルは対象のモードにだけ発動する。VALORANT以外の遺物でVALORANTの報酬を増やすことや、ユナイト限定装備を必須化するコンボは禁止。
- 大額ジャックポットも上限あり。取引系の追加支給は既存のKP操作内に集約し、D1の追加書込を増やさない。
- 外部の確定イベント（VALORANT／QUIZ／通話／スカーミッシュ）は、**新規確定時のみ**装備を参照して、適用分を `relic:${receiptId}` の冪等な入金IDで記録。毎分の未プレイアカウント監視は増やさない。
- 不正支給が判明した場合、報酬額・確率はコードバージョンで追跡し、以後の抽選や追加効果にのみ変更を適用する。

## 既知の制約

- 遺物スキルの実装は**条件に合ったKP追加・控えめな購入還元**であり、VALORANT内のスキル・ポケモンユナイトのプレイ成績・競馬の当選判定・カジノの確率を実際に改変するものではない。
- Discord Activityのキャッシュは `npm run build:activity` のリリース更新で反映する。
