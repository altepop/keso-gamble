# Mリーグ予想の締切

2026-10-30更新。

- 第1試合は従来どおり当日19:00 JSTに締切。
- 第2試合は、その卓の出場4選手をBotが初めて確認してml_lineupsへ保存した時刻から15分後に締切。第1試合の結果が出たことでは締め切らない。
- 選手確定の情報源と取得間隔は既存のキンマwebのテキスト速報を継続する。公表時刻そのものではなく、Botが確認して保存した時刻を基準にする。
- 同じ発表を再取得しても初回時刻を変更せず、15分の期間を延長しない。複数卓はそれぞれ独立して判定する。
- その試合の結果が確定した場合、/mcloseによる開始報告がある場合、当日24:00になった場合は従来どおり先に締切。選手確定を取得できない場合も翌日まで受付を残さない。

Activity・/mleague・/mbetの候補・確認画面・最終購入は同じmlCloseAt/mlOpenを使う。Activityと出場決定のお知らせに締切時刻を表示する。例：21:00に第2試合の選手を確認した場合は21:15締切。締切ちょうどの新規購入・締切前に作った確認ボタンの締切後の購入は拒否し、KPを引かない。

既に購入済みの予想を、新しいルールだけを理由に遡って取り消したり返金したりしない。出場しなかった選手の返金、/mclose後の購入の返金、倍率・週間購入上限・精算方法は維持する。設定変更やDB migrationは不要で、既存ml_lineups.atを使う。
