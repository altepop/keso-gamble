# ソロ指名とルーレット

## 現在の指令価格（2026-11-07）

| 指令 | 基本価格 | 達成条件 |
|---|---:|---|
| アンレ | 12,500 KP | 指名後に開始したアンレを完了 |
| コンペ | 40,000 KP | 指名後に開始したコンペを完了 |
| ソロコンペ | 250,000 KP | ソロと確認できたコンペを完了 |
| ソロデスアンレ | 300,000 KP | 指名後に予約したソロのデスアンレを完了 |
| 負け怖コンペ | 1,000,000 KP | 指名後に開始したコンペで1勝 |

負け怖コンペは負け・引き分けで終わらず、次のコンペへ継続する。ソロ指定はない。ほかのモードの勝利、発令前に開始した試合、未完了・勝敗不明のデータでは達成しない。負け・引き分けのたびに本人へ継続を通知し、同じ試合の再取得では通知を増やさない。

発令時に一度だけ消費し、継続中の追加の指令代や達成時の返金はない。通常の試合報酬・敗北時のKP減額は既存ルールどおりで、指令による試合報酬の増減はない。株主優待の既存割引（最大2,000 KP）と交換回数制限を適用する。一人につき進行中の指令は一件。既存の価格は今回変更しない。

価格感の参考：コンペの通常勝利報酬900 KPだけを足すと、通常コンペ指令は45勝、ソロコンペは278勝、ソロデスアンレは334勝、負け怖コンペは1,112勝ぶん。これは負け・遺物・ほかのゲーム収入・優待を除いた単純比較で、実際の所要時間やユーザーの中央値ではない。気軽な指名には高めで、ソロ系と負け怖は高級枠。


ソロ達成には本人と味方のparty_idが揃い、本人のparty_idが試合内で一人だけであることが必要。情報不足なら達成保留。ソロデスアンレは購入後に `/death start` でアンレを予約し、その予約に結び付いたソロ試合のみ達成。既存のデス判定・コンペ行きルールを維持する。開始前の試合や通常アンレで達成しない。ソロ判定の本番データが欠ける場合は手動で達成を偽装しない。

ルーレットはシングルゼロのヨーロピアン式。0〜36をタップするストレート、赤黒、偶奇、1〜18/19〜36、各ダズン、各列。払戻は掛け金込みでそれぞれ36倍、2倍、3倍。0はストレートの0だけ当たり。1回につき1種類。複数箇所同時・スプリット等は今回含まない。サーバー乱数・残高・操作IDによる再送防止を維持。

2026-10-27追記: 数字指定は複数選択・数字別の掛け金に対応。数字ごと100 KP以上、1回合計20,000 KPまで。選択数字と金額を一つの操作IDで確定し、一度の抽選で当たった数字の掛け金だけ36倍。合計額の一括減算と払戻は既存の原子的サーバー決済を使用。外側ベットとの同時賭けは未対応。
