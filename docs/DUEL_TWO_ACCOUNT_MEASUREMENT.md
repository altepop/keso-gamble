# 決闘2人実測キット（手動検証専用）

この手順はDiscord実アカウント2人の対戦反映速度をユーザーが実測するための記録様式である。実測はまだ実施していない。秘密情報・KP・認証トークン・D1の収集や共有を求めない。

## 事前確認
- 参加者2人が同意し、Discord上で双方がKESO PLAYを開く
- 使用端末・OS・接続種別・画面内のゲーム名・ビルド版のみ記録
- 操作未確認の表示がある場合は、先に同じ操作IDの結果を確認し、新しい操作を再送しない
- 賭けKPを伴う実操作は参加者が自分で判断して行う

## 測定
1. Aが「着手を確定」を押す時刻を動画または高精度時計で記録。
2. Bの画面に同じ着手がサーバー確定として表示された時刻を記録。
3. 10手以上を対象とする場合でも、各手のタイムスタンプと観測可否を残す。画面が読み込めない手は欠測とする。
4. 参加者間で時刻を比較する場合は同一録画に両画面を収めるなど、時計同期の方法と誤差を明記する。
5. サーバー確定表示ではない演出、ローカルタップ時の表示と混同しない。

## 解釈
- 端末内の「タップから自画面の確定表示」は相手Bへの反映時間を示さない。
- 1秒以内かは、欠測を除いた各試行の個別結果と時計誤差を確認して判定する。
- Durable Objects実使用量、認証付きウォレット本番スモーク、Discordエントリーポイント実切替は別の未確認事項として扱う。
- ログにトークン、相手の隠し手札・数字・サイコロの出目、個人情報を含めない。
