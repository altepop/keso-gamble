# KESO COACH の表示刷新

## 分割と変更範囲

PR1 (#600) は `coach.html` のCSSとトークン検証のみ。8px/12px/999px、4px基準の余白、#FF4655と#0F1923系へ統一した。CSS以外のHTMLとJavaScriptは変更前と同一であることを比較した。

PR2は画面構造と文体を統合する。分析・課題選択・100件のカタログ・API・認証・収集・報酬には変更を加えない。`coach/reader.js`、`coach/benchmarks.js`、`coach/practice.js` は元のバイト列を維持する。

## 画面の順番

1. 試合 → 速報 → 分析 → 今日の課題 → 次の試合で確認。現在地は閲覧している画面を示す。Discordへの速報配信成功や、本人が実際に練習を完了したことを示す帯ではない。
2. 選手を選び、改善された点を確認する。改善と判定できない場合は改善を捏造せず、今回の記録を次回の比較へ使うことと、続けたい点を示す。
3. 既存の `choose()` が返した先頭の課題1件を主役にする。起きていることと既存指標1つ、実施手順、次戦の確認方法、次回の振り返り場所を順に並べる。対応する数値がない場合は対象試合数を示す。
4. ほかの候補・条件、試合別解説・詳細データ・留保・出典を折りたたみに残す。神戸のアカウント単体、5人比較、7タブも操作可能なまま整理する。
5. 収集状況・停止/再開・更新・安全コピーを最下部へ分離する。エラーと読み込み中だけは上部にも表示する。

## 文体・可読性

主役の文面はです・ます調の完成した文章にする。既存データ由来の文章は表示境界で敬体へ整え、原データや安全コピーの値を変更しない。長い説明は文ごとに分け、課題の手順は番号付きにする。本文は16px以上・行間1.9。日本語の語と助動詞をまとめて折り返し、URL・数値・入力欄は変換しない。

射撃場を使う表示はダイヤ帯向けに案内する。射撃テストはミディアムからハードへ、移動照準はプラクティスでストレイフONとする。別の設定として説明し、同時に有効化できると断定しない。課題ID・優先度・選定条件・元の実行データは維持する。

公式アートを外部ロードせず、公式寄りの色と切り欠きの意匠で構成した。ページからの追加通信はない。

## 検証

320px/375px、主役カード1件、4段階、現在地、本文16px・375pxの短い段落、語の折り返し、折りたたみと従来操作、ダイヤ帯設定をChromium/WebKitで確認する。APIの呼び出し件数、本人照合、安全コピーの内容、診断の値、更新/停止の挙動は既存の回帰テストで維持する。

敬体変換の繰り返しによる破損、100件のカタログの非変更、PDCAと運用コントロールの保持を単体テストで確認する。本番デプロイの成功と画面の実機操作は区別して報告する。検証に使う画像はテスト用データであり、実データの画面とは称しない。
