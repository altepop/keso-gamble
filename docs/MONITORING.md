# 監視状態（システムの状態）

Activity の「資産 → システムの状態 → 状態を見る」で、自動処理が動いているか、未精算や送信待ちがたまっていないかを確認できる。

- 取得元：`GET /api/kp/health`（KP口座に接続したメンバーだけ。集計の数字だけを返し、個人のIDや額は返さない）。
- 処理ごとの状態：Worker の定期処理（毎分）の各ジョブを `track()`（`services/valorant-results/src/health.ts`）で包み、`kp_health` に最後の成功・最後の失敗・連続失敗回数・失敗の理由を残す。
  - 成功の記録は5分に1回まで（D1の書き込みを抑えるため）。失敗はすぐ記録する。
  - 失敗の理由は、URL・長いトークン・長い数字を消して80字まで。
  - 表示：✅正常／⏸️止まっている可能性（10分以上成功の記録がない）／⚠️失敗中／・まだ記録なし。
  - 対象：VALORANT速報・KP、雀魂の監視、ユナイトの監視、通話の計測、株の相場、馬主の出走・賞金、馬のプレゼント、競馬の精算、借KPの返済・利子、冠レース、Mリーグの結果・精算、稼ぎchへの投稿、競馬の実況。
- たまっているもの：Mリーグの未精算の予想と結果待ちの試合、競馬の未精算の馬券、雀魂の承認待ち、借KPのある人数、稼ぎch・速報chの送信待ち、VALORANTのKP反映待ち、ユナイトを読めていない人（非公開・読み取り失敗・履歴の食い違い）。まだ一度も動いていない機能の表は「—」。
- 注意：ジョブの中で自分で例外を受け止めて記録している処理（例：雀魂の監視の取得失敗）は、ここでは「正常」に見える。雀魂は `GET /api/mahjong/status` に詳細がある。
