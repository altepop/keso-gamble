# Phase 10 承認ゲートの全組合せ検証（既存ロードマップA）
P10の承認不要の検証強化のみ。観戦公開ポリシー、同期方式、大会規模・方式、演出音声、運営者ロールの5項目はすべて**PROPOSED／未承認**。
- 音声承認2件・閲覧/チャンネルの同意2件・ミュート/軽減表示2件の計64組合せをテスト。許可条件を全て満たす組合せ以外は拒否する。実音・通話送信はしない。
- ギルド越境、明示許可なし、認証ギルド欠落を拒否する。
- 大会方式と運営者ロールは両方の承認がなければ開催公開できない。
今回のテストは承認されたアクセス権限の存在を意味せず、サーバー/Activityの新しい公開ルート、実D1書込、通知の配信、報酬有効化は一切しない。ロードマップAの機能範囲を縮小しない。Phase 9本番ポリシーINSERT禁止。
