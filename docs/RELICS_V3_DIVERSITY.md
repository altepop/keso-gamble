# 遺物Ver.3：Steam達成率25%以上／10〜25%・全体／特殊／市場系・ユナイト累計

## 確定ルール
- **過去に獲得したSteam実績を一切遡及対象にしない。** 監視登録時のSteam実績スナップショットはこれまでどおり基準として保存し、そこから後に解除された実績が `kp_steam_events` として正式に記録された場合にのみ遺物の取得候補に入る。監視処理自体、KPの4段階支給額（100/300/1000/5000KP）と1日5000KPの上限は一切変更しない。Zup!も除外しない。
- **Steam遺物の区分**：解除率25%以上～100%「旅路」、10%超～25%未満「挑戦」、5%超～10%「熟練」、1%超～5%「偉業」、0.1%超～1%「神話」、0.01%超～0.1%「深淵」、0.01%以下「異界」。境界25%は「挑戦」、25%超は「旅路」、10%は「熟練」。
- Steamの報酬実績台帳にあるものは解除率を問わず1実績1個まで受取可能。任意の過去実績の検索やバックフィルは実装しない。受取済みの同じイベントIDを再請求できない。
- Steam専用遺物は12種類の能力型を用意し、Steamのapp IDと実績IDから一意に割当てる（再入手や受取順による変化なし）。固有実績名と能力型を組み合わせて表示し、専門スキル・全体スキル・市場横断スキルのいずれかが実際の確定報酬で発動する。称号や戦力だけではない。
- **通常遺物140種類**（旧98種類をすべて残し、新たに全モード共通・経済横断・株裏戦略・競馬裏戦略・カジノ裏戦略・特殊条件6系統×7レアを追加）。既存のアイテムID・所持数・装備数は維持する。ガチャ200KP／回とLv1〜10の確率配分は一切変更しない。
- 一般～超越の強さは単純比例させない。全体に広く効く代わりに倍率が低い遺物、株・馬券・カジノの特定条件で高く効く低／中レア、報酬が末尾7・奇数という特殊条件で高く効く遺物を用意。いずれも他のゲームの限定遺物の所持を解放条件にしない。
- **ユナイト限定10種**：連勝1～5（従来の保存上限を超える6連勝以上を前提としない）＋累計10/25/50/100/200勝。ランク戦の確定済み`unite_rewards`のみ証拠。累計勝利は本人レシートのwin=1のみを集計する。1人各1個で、同時装備は1個まで。単独性能を高く、通常・Steam遺物の強化条件や推奨コンボにユナイトを登場させない。
- 全モードで発動する能力も、元の確定報酬を検証した後だけ計算する。対戦モードの追加KPは元報酬の15%かつ1件合計80KP、カジノ・株・競馬・Mリーグは対象額の1%かつ全体1日120KPの既存制限内で有効。
- Zup!の制限、過去実績の補償、遡及認定、Steam KP報酬の値下げは**一切しない**。既存のSteam報酬を維持したまま、ほかの実績を取得すると別の遺物能力も得られる設計とする。
- 新たな監視cron、マイグレーション、DBテーブル・インデックスは追加しない。Steam受取候補は遺物画面を開いたときのみ取得。
