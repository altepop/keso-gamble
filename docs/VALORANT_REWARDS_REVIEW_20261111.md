# VALORANT報酬の改修と次の案

## このPRで実装する承認済み仕様

- スカーミッシュ：50 → 250 → 750 → 2,000 → 5,000 KP。5勝目は自動受取。既存の保留額を勝手に上書きせず、次の勝利から新しい段階額を利用する。続行後の敗北で失うのは保留分だけ。
- アンレ：勝利報酬は70 KP（87.97%）、500（8%）、2,000（3%）、10,000（1%）、100,000（0.03%）。従来の370は加算しない。勝利の共通ラッキー倍率は追加しない。ユーザーの追認により、遺物は10万KPを含む当選額の全額に掛ける。
- アンレ敗北：通常−50・味方最下位−200を維持。共通倍率と遺物の追加損失も既存の処理を利用する。
- 旧アンレは初期化時に一度だけ記録する `unrated_v7_started_at` より前に開始した試合、旧inboxのpolicy、精算済みレシートで保存する。再送で再計算・再支給しない。
- 新アンレのジャックポット通知は賞金全額を表示する。旧レシートの `lottery` と新レシートの `jackpot` を混同して遺物計算から引かない。
- D1追加テーブル・定期監視なし。初期化の既存SQLに適用時刻キーを1つ追加し、アンレの既存設定読取の中で主キーを参照する。他モードの支給額・乱数・処理は変えない。
- Activityの案内を更新。エスカの既存抽選（1/24、等級35/28/20/13/4%）と食い違っていた15%表記も修正する。エスカの支給ロジックは変更しない。

## 評価と試算

アンレは下振れをなくす一方、遺物なしの勝利平均は470から291.579 KPへ約38%下がる。「誰でも以前より多く稼げる」変更ではない。10万KP当選と遺物を掛け合わせるため、装備格差と最大支給額は拡大する。

通常各1個、変異・色違いなしの「暴走する鎖の心臓／深淵の契約書／双面の魔導銀貨／四重奏の指揮杖」で、90分制限等を満たす場合の例：

| 当選額 | 遺物込み |
| --- | ---: |
| 70 | 1,692 |
| 500 | 8,847 |
| 2,000 | 34,747 |
| 10,000 | 172,877 |
| 100,000 | 1,726,839 |

この構成の勝利平均は旧5,454、新5,485.4441 KP。今回の構成では平均が近いが、他の装備の平均や最大額を保証しない。所持数・変異・色違い・特殊効果によって変わる。

スカーミッシュは従来、勝率65%が独立・固定なら3勝で受取が約79.51 KP/対象試合、5勝狙いは約68.91で、深追いの見返りが弱かった。新配分では3勝約99.38、4勝約152.11、5勝約229.70。これは遺物なし、試合時間・選択待ち時間を含まない更新過程の計算。

## 以下は提案のみ。コードには入れない

### チーデス：パーティの共同課題

組んだだけの定額ボーナスは、短時間周回に報酬が偏る。勝利・勝ち方・各参加者の貢献まで確認する案を推す。

- 2人以上の同一パーティをAPIのparty_idで確認する。情報が足りない場合、勝手に同じパーティと扱わない。
- 勝利し、チームのキル差20以上、パーティ全員がキル＋アシスト20以上なら各＋200。
- キル差35以上、パーティ全員がキル＋アシスト25以上なら各＋500。
- 現在の個人成績ボーナスと高い方だけを採用。基礎70は据え置き。
- 数値は実試合で達成頻度を見て確定する。通常の同じチームと、事前に組んだパーティを混同しない。初期実装前にHenrikが実試合でparty_idを返すか確認する。

### スイフト：5対0の圧勝に絞る

5対1などへ広げると以前の「5対0だけ」という特徴が薄れる。成長要素を重ねるとスパクラとも被る。

- 通常の勝利180は据え置き。
- 5対0で確認できた圧勝ボーナスを＋400から＋600へ。
- さらに本人のキル＋アシスト15以上なら＋150（5対0のときだけ）。
- 上2つを足しても安全枠の遺物上限は既存どおり。試合時間や未確認の最終ラウンド情報は条件にしない。

### エスカ：参加前にリスクが分かる一戦勝負

「1/24で大勝負」は、大勝負だけを見ると10試合何も出ない確率が約65.3%。その一方、0.1%で他のゲームで貯めた手持ちまで半額になる。起きにくい刺激と、資産全体への大きな罰が同居しており、敬遠の原因になり得る。実際に遊ばなくなった理由はメンバーの反応や試合履歴で別途確認する。

- 通常エスカは今の基本70と成績条件を維持する。
- 特別な大勝負は本人が「次の1戦」で参加する。受付時に勝利時の賞金・敗北時の最終損失上限を見せて固定し、選択後に開始した試合だけを対象にする。
- チャレンジごとに500／1,000／2,500／5,000／15,000の勝負級を抽選。成績30／35キルとKD条件で昇格・上乗せを設け、結果画面で段階が上がる演出にする。
- 勝負頻度は本人が選べるので、強制の1/24待ちをなくせる。
- 保有KP半額は廃止候補。負けのリスクを、その一戦に事前表示した範囲に限定する。上限は遺物込みの最終損失で定義する。
- 低確率の大当たりは残す。具体的な確率・金額は勝率50/65%・装備別に計算してから確定する。支給期待値だけでなく、最大損失と周回時の供給量を見る。

単に抽選回数や音を増やすより、「挑戦前から勝てばどうなるか分かる」「試合の成績で結果を伸ばせる」を優先する。上記は実装・本番有効化していない。
