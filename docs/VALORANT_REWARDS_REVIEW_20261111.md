# VALORANT報酬の改修案と確認状況

このPRは追加要望を反映中の下書き。本番には未反映。アンレ・スカーミッシュ・チーデス・スイフト圧勝は確認済み。エスカパワーの具体的な計算幅と、大勝負に超ラッキー／手持ち半額を含めるかは回答待ち。

## 確認済みの変更

### アンレ

勝利報酬そのものを70 KP（87.97%）、500（8%）、2,000（3%）、10,000（1%）、100,000（0.03%）から1回だけ抽選する。従来の370は別加算せず、勝利の共通ラッキー倍率も加えない。ユーザーの明示回答により、遺物は10万KPを含む当選全額に掛ける。

敗北の通常−50・味方最下位−200と、既存の共通倍率・遺物損失補正は維持。

最低保証は改善するが、遺物なしの勝利平均は470から291.579 KPへ約38%下がる。誰でも増額になる変更ではない。通常各1個、変異・色違いなしの「暴走する鎖の心臓／深淵の契約書／双面の魔導銀貨／四重奏の指揮杖」では、勝利平均が旧5,454から新5,485.4441 KP。10万当選は遺物込み1,726,839 KP。装備と最大支給額の差は拡大する。

### スカーミッシュ

50 → 250 → 750 → 2,000 → 5,000 KP。5勝目は自動受取。保留済み額を上書きせず、次の勝利の段階から新額。続行後の敗北で失うのは保留分のみ。

勝率65%が独立・固定なら、遺物なしの対象試合平均は、旧3勝受取79.51／5勝狙い68.91 KPから、新3勝99.38／4勝152.11／5勝229.70へ。試合時間・選択待ち時間は含まない。後半を狙う価値を上げる。

### チーデス

個人の30キル・KD1.5で＋200、40キル・KD2で＋500は維持。

- APIで同一パーティを確認した2人以上で勝利。
- チームのキル差20以上かつパーティ全員のキル＋アシスト20以上で各＋200。
- キル差25以上かつ全員のキル＋アシスト25以上で各＋500。
- 個人成績とパーティの高い方だけを支給。基本70は据え置き。
- 自チーム全員のparty_id、両チームの人数・キル、パーティ各人のアシストを確認できなければ共同ボーナスなし。単なる同じチームをパーティと扱わない。

### スイフト圧勝

通常勝利180は据え置き。両チームの結果で5対0を確認した勝利だけ＋600。本人のキル＋アシスト15以上なら、その圧勝にさらに＋150。通常時は合計780／930 KPに共通倍率を1回だけ適用。5対1などには上乗せしない。

## エスカランク：認定・ACT引継ぎ・エピソード更新

KESO独自のランク。VALORANT本体のランクや公式MMRとは連動しない。通常の3勝／3敗シリーズ制は維持し、表示をランク名・RRに変更した。

- アイアン→ブロンズ→シルバー→ゴールド→プラチナ→ダイヤモンド→アセンダント→イモータル→レディアント。レディアント以外はⅠ・Ⅱ・Ⅲ。100RRで1段階、300内部表示ポイントで1ランク。レディアントは人数制限なし。
- 初回は認定3試合。初期表示ポイントは200×勝数＋成績補正（最大5）。0勝アイアンⅠ／1勝アイアンⅢ／2勝ブロンズⅡ／3勝シルバーⅠ。初期案から全体を2ランク下げ、1勝ごとの200RR差を維持する。
- 同じエピソード内のACT更新は認定1試合。前の確定ランク・RR・内部レートを引き継ぐ。認定敗北は表示ポイントを下げず、認定勝利なら20＋成績補正（最大3）だけ上げる。未完了のシリーズは持ち越さない。
- エピソード更新は認定3試合。通常は2ランク（600ポイント）低下。ゴールドⅠ→ブロンズⅠ。前回の内部レートと認定結果が強ければ1ランク低下、維持、最大1ランク上昇まであり得る。アイアンⅠより下にはならない。
- エピソード再認定の式は `max(0, 前表示−600＋clamp(前内部−前表示＋100×(勝−敗)＋成績補正, 0, 900))`。前表示・前内部が1000で認定1勝2敗なら400（2ランク低下）、3勝なら700（1ランク低下）。前内部が1300で3勝なら1000を維持、1600で3勝なら1300へ昇格。
- 内部レートはKESOの試合結果から作るサーバー値。初認定で表示と同じ値を設定し、その後は各勝利＋30／敗北−30に個人成績0〜3を加えて更新。ACT・エピソードでも0へ戻さない。API・画面に数値を返さず、ブラウザーからの申告も受けない。
- 認定後は3勝／3敗でシリーズ終了。3勝0敗＋100、3勝1敗＋70、3勝2敗＋40RR。負け越しは逆の幅。
- 個人成績：30キル＋1、15キル以上でKD1.5以上＋1・KD2以上でもう＋1、15アシスト＋1。1試合最大3、認定・シリーズ合計最大5。通常の敗北シリーズは減少を軽減するだけでプラスにはならない。欠損した成績は推測しない。
- ACTは試合データの `season.id`、エピソードは `season.short` の `e11a1` のようなコードの接頭部で区分。`v26a1` 形式も同じ接頭部単位に対応。未対応・欠損時はKPのみ通常精算し、認定・ランクだけ保留する。カレンダーや連番から境界を推測しない。Henrikのseason短縮コードの例は[公式API資料](https://docs.henrikdev.xyz/valorant/api-reference/mmr)を参照。
- 認定中は前ACTのランクと必要試合数を表示。今ACTの最高ランク、認定済み上位10人、過去3ACTの最終・最高ランクを表示する。遅い旧ACTの記録で現在ACTを巻き戻さない。
- KP残高とランクは別。参加費・シリーズ追加KPはない。新エスカは特別抽選をやめるが、基本70／0／−30・既存の成績条件・共通倍率を維持する。

相手の強さを補正していないため、公式の実力指標として扱わない。導入後の対局だけを対象にし、過去を自動で再採点しない。このPRは未配置なので、従前の5試合プロトタイプのテーブルを本番で破壊・初期化する処理は追加していない。

## 大勝負のスイフト移設（範囲は回答待ち）

現案は五等級の大勝負だけを移す `specialScope: big-only`。超ラッキー・手持ち半額まで移すかは未承認。`all` への変更はユーザー回答後に検証する。

- 大勝負1/24。五等級500／1,000／2,500／5,000／15,000 KP、等級確率35／28／20／13／4%。
- 勝利はプラス、敗北はマイナス。引き分けは抽選しない。
- 通常の基本報酬を置き換える。5対0＋600と圧勝貢献＋150は別途加算し、共通倍率は合計に1回だけ適用する。
- スイフトの遺物は既存の安全枠を維持。勝利追加は元報酬まで、敗北の遺物追加損失なし。
- 結果の保存・再生に既存の抽選履歴表を利用し、KPイベントへの主キーJOINでモードを区別する。旧エスカの確定履歴は当時の名前で再生できる。

「何も出ない」大勝負1/24は10試合連続で出ない確率が約65.3%。短いスイフトへ移すと時間当たりの抽選機会は増えるが、ルーレットを見直しても再抽選・再支給はしない。

## 適用境界・D1・検証

`valo_v7_started_at` を既存の初期化SQLで一度だけ保存し、対象モードの既存設定読取内で主キー参照する。追加のD1往復を作らず、新ルールは適用後に開始した試合だけに使う。旧inbox・確定済みレシートは元のpolicy・金額・抽選分離を保持する。V7のアンレjackpotを旧式の抽選額として遺物対象から引かない。

エスカのパワーはACT別集計・現在ACTの主キー参照・試合ごとの一意レシートで管理する。通常の新規支給は既存の確定バッチ内にパワーのレシートを追加し、トリガーでKP・パワー・状態版数を同一トランザクションに確定する。ACT情報が遅れた場合も、支給済みKPを変えずにパワーだけ一度反映できる。現在ACTと未反映レシートは既存の監視読取にJOINし、追加の読取往復を避ける。ACTが変わった時だけ現在ACTを更新し、遅れて届いた前ACTは現在ACTを巻き戻さない。上位10人はACTを含む索引で取得し60秒キャッシュ。本人の過去ACTも索引で3件だけ取得する。初回のACT別行作成時のみ、認定済みの前ACTをギルド・本人・開始時刻の索引で1件参照して引き継ぐ。新しいcron・外部API呼出し・全試合履歴の再集計は追加しない。
