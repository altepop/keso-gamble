# KESO DUEL ロードマップA — Phase 10のユーザー最終決定（2026-11-22）

## 優先順位
本書は同日のユーザーによる「フェーズ10の5項目：ユーザー決定」を正確に記録し、以前の「二者同意・2秒固定ポーリング・大会2～16人の開催・専用運営者ロールを必須とする」提案、2026-11-20設計ドラフトおよび過去のPROPOSED文書の判断より優先する。設計承認とコードの実装・デプロイ・実機動作は異なる。

## 1. 観戦公開ポリシー — 承認済み
- ギルドに登録済みの**本Discordアカウント**は、同一ギルドの進行中の決闘を観戦してよい。終了済み試合は直近1時間のサーバー確定記録を閲覧可能とする。
- 参加者双方からの同意、招待、オプトインは**不要**。旧PRで開発された同意テーブル・招待UIは廃止し、公開設定入力の負担を無くす。
- **登録済みサブDiscordアカウントは観戦禁止**。登録時に作成済みの「本Riot ID＋サブDiscord ID」照合用SHA-256ダイジェストを再利用して判定し、DiscordユーザーIDの平文対応表・短縮ID・推測した表示名を公開しない。
- サーバーは接続済みKPセッション、ギルド一致、本人のKP参加者登録、実ウォレット・状態、サブアカウント除外を毎回確認する。URL・試合IDを知っているだけでは観戦できない。
- 秘密手札、数字の正解、山札、セッション、未確定操作、KP残高は公開しない。ゲーム6種目の`spectatorPublicSnapshot`だけを使う。
- 新たなサブアカウント登録があれば、既存の照合用ハッシュ登録も更新する。未登録の複数アカウントまで自動識別できるものではない。

## 2. 観戦同期方式 — 速度優先、承認済み
- **既存のDurable Objects経由Server-Sent Events（SSE）を第一選択**とする。ゲーム確定イベントからIDとversionだけを本アカウント観戦者へリアルタイム配信し、受信直後に認証付きAPIでサーバー確定スナップショットを取得する。
- SSEが利用できない、プロキシ側で停止する、ギルドの既存2時間/UTC日SSE予算に達した場合のみ、表示中の試合を**2秒間隔でポーリング**する。SSE正常時は15秒の補正取得。非表示タブでは停止する。
- 再接続、重複イベント、同版・旧版は版番号によって抑止し、未確定結果や過去状態への逆行表示は行わない。
- 実測遅延、複数端末、上限・Discordアプリ内プロキシの挙動は本番実機で未確認。SSEが未到達でも定期取得で継続する。

## 3. 大会規模・方式 — 保留（Phase 10完了の必須条件から除外）
- ユーザーは大会を当面開く予定がなく、形式の具体的な決定も見送る。
- 既存のブラケット純粋関数・テスト資産は保持するが、大会受付、運営UI、順位確定、賞金・KP追加報酬の本番有効化を急がない。
- 大会未実装を理由に、通常の観戦・同期・演出を対象としたPhase 10の完了を塞がない。

## 4. 演出と音声 — 再生・Discord通話への送信とも承認済み
- **実音の再生、およびDiscord通話への音声送信をユーザーが正式に承認**した。改めて方式選択の判断を求めない。
- 端末での音声通知は利用者の操作で有効にする日本語読み上げから開始する。消音、端末の再生許可、権利確認を優先し、既存の音楽再生や通話を突然遮断しない。
- Discordボイスチャンネルへの実送信は、本リポジトリの既存音楽ボット／Discord音声基盤への経路と技術的な資格情報・配備を確認して接続する。**承認済みと実送信稼働済みを混同しない**。コード・音声品質・権利を検証できない段階では「未実装／未確認」である。
- 既存の著作物音源の無断再生はしない。演出本文の定型通知は個人情報・秘密カードを含めない。

## 5. 運営者ロール — 保留・所有者のみ暫定
- 大会を開催しないので、専用運営ロールの設定や配布は不要である。
- 将来大会運用を導入する場合の暫定権限は、既存の認証済みギルド所有者（ユーザー）だけとする。ブラウザの自己申告や役職名の一致だけで権限を付与しない。
- 当面は大会管理エンドポイントを公開しない。運営ロール未実装を理由に通常のPhase 10観戦機能をブロックしない。

## 品質ゲート
各関連PRにつき**現行headのCI全緑→mainマージ→同一main SHAのPages/Worker両配備成功→PR本文へ検証結果追記**を維持する。Phase 8のiPhone/Discord実機、観戦遅延・音声通話経路、リアルなKPユーザー登録確認は、証拠がない場合に限り「未確認」とする。

Phase 9報酬・Cloudflare D1有効化は独立ゲートであり、観戦PRでKPや報酬設定を変更しない。Phase 11とPhase 12の実装進捗も、PRやデプロイで未確認のまま完了と記録しない。
