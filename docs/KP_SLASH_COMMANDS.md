# DiscordのKP・競馬コマンド

同じサーバーのDiscord署名検証済みInteractionsから本人の口座を使う。管理者権限は不要。ランキングだけは実行したテキストチャットへ公開し、その他は本人だけに表示する。ランキングのユーザー表示でも通知メンションは飛ばさない。

- `/kp ranking`: サーバー内の使えるKP残高上位10人。同額は同順位（1位、1位、3位）。株や馬の評価額は含めない。口座・残高を変更せず読むだけ。
- `/kp balance`: 本人の残高と直近5件の入出金。初参加は0 KP口座を作る。初期配布はしない。
- `/keiba`: 受付中の出走馬・馬番・単勝/複勝倍率・発走/締切時刻。
- `/bet horse:3 amount:500`: いま受付中のレースの3番に500 KP・1着当て。horse の欄をタップすると、馬名と倍率（1着当て・複勝）と発走時刻の一覧が出るので、選ぶだけでよい（Discordのオートコンプリート。Worker がその場で返す）。type を選べば複勝にもできる。古い形の `race:21:00` が送られた場合は、受付中のレースと一致するときだけ受け付ける。返答には、レース名・馬名・当たったときの払戻額を表示する。

金額は100 KP以上・100 KP単位。1週間50,000 KPまで。購入後の取消は不可。発走時刻は必須で、受付中のレースと一致しない場合は拒否する。日付はDiscord操作の作成時刻から決め、0時をまたぐレースも扱う。再送時もレースIDを変えず、同じ操作IDなら元の購入結果を返す。Activityと同じoperateKp/台帳/残高/精算を使う。

既存VoiceGatewayが保持するBot認証で、対象アプリとguildを確認し、3コマンドを個別POSTで登録する。既存death/valo/Entry Pointを一括上書きしない。同名の別コマンドは拒否する。成功版をDOに保存し、失敗時は5分後に再試行。登録失敗は通話監視を停止しない。statusのcommandsRegistered/commandsErrorで状況を確認できる。秘密値の追加入力や再発行は不要。

検証はSQLiteメモリDBと模擬Discordのみ。本番でテスト用馬券の購入やKP発行はしない。

`GET /api/kp/commands` は公開コマンド定義と版、アプリIDだけを返す。口座・guild・秘密設定は返さず、DBへアクセスしない。既存QUIZのREST登録処理がこの定義を読み、変更版だけ個別登録するため、通話セッションの更新待ちでもコマンド定義を更新できる。
