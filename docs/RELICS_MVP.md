# KESO遺物 MVP（200KP召喚、Steam・ユナイト限定）

## 方針（2026-11-02）

- 召喚価格は **1回200KP**。10・100・1000連は割引なし。無料券を通常のSteam実績報酬には使わない。
- 実装するのは「通常」「Steam限定」「ポケモンユナイト限定」の3入手元のみ。**KESO LOOP由来遺物は未実装**。
- ユナイト由来は単独で非常に強い（戦力390／480／620）。通常超越の戦力350より高い。しかし、共通・Steamの育成目標や説明でユナイト由来を必要条件にしない。相性ボーナス・推奨組み合わせ・セット完成のUIは作らない。
- ユナイトをプレイしない人にも通常・Steamだけで収集／4枠装備が完結する。
- **戦力は遺物コレクション・装備評価の数値**。現段階でVALORANT・雀魂・ユナイト・競馬・株のKP増幅や、別ゲームの成績への優遇はしない。レア入手を既存経済の永久倍率につなげない。

## 通常召喚

- バッチ1/10/100/1000回。上限は1,000連／リクエスト（200,000 KP）。
- サーバー側のcrypto RNGからレアリティと種類を抽選、KP差引とコレクション反映は既存 `kp_operations` の一つの確定操作にまとめる。1,000連でもD1に1,000件書かない。
- 総召喚数500回ごとに召喚レベル+1、最大Lv10。
- 超越確率：Lv1=0.001%、Lv10=0.01%（中間は0.001%刻み）。天井なし。超越は通常の合成では作れない。
- それ以外の確率（現行固定）：古代0.24%、神話1.75%、伝説5%、希少13%、上質28%、残り一般。Lv上昇で増えた超越分は一般から差し引く。
- 同じ通常遺物が出たら所持数量+1。重複数のlog2段階に応じて、装備戦力を5ずつ（最大+60）自動強化する。単なる外れの積み重ねでも成長する。実戦効果を持つ強化合成は別フェーズで未実装。
- 大当たり演出用の結果は古代・超越のみ、集計値はレアリティ別の数。大量召喚で巨大なD1書込やレスポンスを発生させない。

## Steam限定

- 既存Steam OpenID本人接続／有料ゲーム・プレイ時間120分以上／監視開始後の新規実績を、**既存の `kp_steam_events` の証拠**として扱う。ブラウザから渡された実績名や解除率を信用しない。
- 世界解除率10%以下のイベントをプレイヤーが受取操作すると、実績に由来する固有のSteam限定遺物を一度だけ付与。実績名を安全にエスケープして表示する。
- 世界解除率別戦力：5〜10%は75、1〜5%は105、0.1〜1%は150、0.01〜0.1%は220、0.01%以下は320。
- 既存実績の遡及認定は初期版では対象外。過去に解除済みの実績の扱いは別途仕様検討。
- 受取済み同一イベントの複製不可、Steam限定保有は最大200種類。売買不可。

## ユナイト限定

- 既存UniteAPI監視で確定済みの `unite_rewards` のランク戦勝利・連勝記録だけを信用する。プロフィールの申告・ブラウザからの勝利数・未精算試合は信用しない。
- 初勝利：「テイアの守護核」戦力390。
- 3連勝：「伝説を奪う手」戦力480。
- 5連勝：「レックウザの逆鱗」戦力620。
- 各遺物は1人1種類、各1個。証拠となる記録が一度あれば、後で負けても消滅しない。**Steamや通常遺物の装備、覚醒、名前、効果にユナイト所持条件を作らない。**
- 3連勝と5連勝を達成しても、通常・Steam遺物へ「ユナイトを組み合わせよ」という誘導やレシピは生成しない。
- ユナイト未プレイ者も単独コレクション・4枠装備を楽しめる。売買不可。

## 装備・経済・不正

- 4枠に自由装備。能力のクロスソース相性レシピ、ユナイト強制のクリア条件はなし。
- 既存の口座セッション確認、リクエストハッシュ、操作の冪等キー、ウォレット版数・State版数競合防止を再利用。支払と付与が同一トランザクションで確定する。
- 借KPが残る際の召喚などKP減算は禁止。装備・外部遺物獲得も既存借KPチェックに従う（初期版）。
- 遺物関係の取得では1秒ごとの定期APIを追加しない。Steam実績候補一覧は遺物画面を開いたときだけ取得。
- 特別なサーバー定期処理・新DBテーブル・追加インデックスは不要。
- 機能の拡張候補：通常重複の強化、より多くの通常遺物、遺物専用の試練、ガチャ大当たりの特別演出、闇市。ただし今回のMVPに含まない。

## 数値の例

- KESO LOOP序盤1,000KPは5連相当ではなく5回相当（10連には2,000KP必要）。
- 第1章50,000KPは250回、第2章300,000KPは1,500回、全報酬351,000KPは1,755回。
- Lv10で超越0.01%のまま1,755回を引けたと仮定した場合、超越1個以上の確率は約16.1%。実際はLv1から段階的に確率が上がるため、それより低い。
