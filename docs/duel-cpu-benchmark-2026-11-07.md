# KESO PLAY 決闘CPU 6モード比較調査（2026-11-07）

対象コミット: `fc1875c25f2465619c4ba1d2e83961a741d9d480`（CPU強化PR #369）。既存のCPUコードと対人戦と共通の盤面／ミニゲーム規則を改変せず、ブラウザ外のNode.jsでCPU同士を対戦させた。

## 調査条件

- 比較: 「強め」対「ふつう」。**同じ疑似乱数シードで先手・後手を入れ替えた2試合**を1組として集計。引き分け=0.5勝換算。
- 盤面3種: シードに基づくランダムな**最初の2手**の後からCPUに操作させる。初期局面の多様性を確保した条件付き対戦であり、全局面を網羅する試験ではない。
- 隠し情報3種: `miniStart`が各試合の秘密数字・ダイス・デッキを生成。CPUには公開盤面と**本人の手札だけ**を渡す。
- 結果判定: `playDuelMove`, `connect4Move`, `miniMove`をそのまま実行し、CPU側に勝敗判定はさせない。
- 試行中のAPI通信・D1アクセス・実KP増減は**なし**。
- ベンチマークソース: `scripts/duel-cpu-benchmark.mjs`。
- GitHub Actions結果: https://github.com/altepop/keso-gamble/actions/runs/42348281310

## 追加診断

### Hit & Blow
強めを先手に置くと600戦中397勝（66.2%）、後手に置くと600戦中208勝（34.7%）。本番のCPU練習はCPUが後手なので、強めであっても実際には先手の通常CPUに負け越す。

同じ1200個のランダムな正解数字を単独推理させ、先後交代の影響を除去した結果:

- ふつう: 平均5.311手、最大7手
- 強め: 平均5.372手、最大8手
- 同じ正解で強めが早かった348件、ふつうが早かった425件、同手数427件。

強めはより多くの候補・回答サンプルを評価しているが、候補を辞書順に間引く手法と、候補内の質問だけを比較する制約が残る。計算量増加と正解速度向上が結び付いていない。必要なのは全候補分割の均等評価、質問候補の多様化、解答できる確率を含む期待手数の最小化である。

### 五目並べ
160戦中86戦が引き分け（53.8%）。強めは相手の次の1手を調べるが、継続四・両三・複数の勝ち筋を追う強制手順の探索ではない。防御はできても、相手を突破して勝つ「詰め」が不足している可能性が高い。

### ポーカー
実戦2,400戦で強めの勝率換算48.9%。手札220組を対象に、各300回の独立した未見デッキで「強めが選択した交換」と「ふつうが選択した交換」を比較した補助試験でも、強めは全手札平均で推定約0.5ポイント劣った（差が小さいため有意な性能悪化と断定しない）。

26通りの交換を各112回ずつ**異なるランダムサンプルで**評価して最大値を採用する手法は、分散による過大評価（最良値の選択バイアス）を生む。改善では各候補に共通乱数で同じ未見デッキを与え、統計的に確かな改善がない場合は安定したふつう戦略を選ぶべきである。

### ブラフダイス
3,000戦で強め53.2%。公開履歴に基づくブラフ確率補正と成立確率の判定は機能しているが、上位難易度としての差は小さい。勝率と確率較正を指標として判定閾値・宣言の適度なブラフ混合率を探索し直す余地がある。

### オセロ・四目並べ
強めに明確な優位があり、現時点ではAI探索の全面変更を急ぐ必要はない。一方、CPU判断時間はふつうより長いため、低速端末での上限・サーバー非接続を確認する必要がある。

## 改善優先度（提案）

1. **最優先**: Hit & Blowの期待情報利得／最小期待正解手数を改良し、後手でもふつうに勝てることを検証する。
2. **最優先**: 五目並べに脅威探索と強制応手探索を導入する。引分率を減らすだけでなく、合法かつ勝ち筋を生む割合を測る。
3. **最優先**: ポーカーのモンテカルロ比較に共通乱数・段階的試行・保守的な基準戦略を導入し、ふつうへの勝率向上を再試験する。
4. **次点**: ブラフダイスの成功確率と公開履歴ベースの宣言・疑いモデルを実験的に調整する。
5. **維持・検証**: オセロと四目並べは局面の多様化、端末処理速度、先手・後手の偏りを確認する。

**100点の定義は未達**。暫定の合格基準として「強め対ふつうで先後を平均した勝率換算65%以上」「違法手0」「低速スマートフォンでも応答可能」「やさしい・ふつう・強めの優劣が単調」「CPUが相手の非公開情報を利用しない」の5条件を採用し、試行数と信頼区間を固定して再判定する。人間との実戦体感は別途検証する。
