# KESO PLAY 遺物システム V7

実装対象は遺物システムの次の11項目である。召喚の既存1/10/100/1000連、200KP/回、既存148種、Steam・ユナイトの検証済み限定遺物を維持する。

| # | 機能 | 実装・制約 |
|---|---|---|
| 1 | ビルド診断 | 純粋な報酬関数で、10ゲーム×4報酬額×勝敗2条件を試算する。平均・最大・最も強いモード・ブレ幅を表示する（実際のプレイ確率ではない）。 |
| 2 | 獲得演出 | 確定済みゲーム精算または新しい検証済み台帳の追加KPのみ、元報酬→合算報酬を表示。音声・動作の強制なし、6.5秒自動消去、手動閉じる。 |
| 3 | 発動ログ | nativeはwallet stateの新着最大30件、verifiedは「relic_effect_logs」へ証憑IDで冪等に記録。既存の台帳がない報酬は再作成しない。 |
| 4 | 呪い反転 | 「虚無の王との契約」＋「双面の魔導銀貨」を装備、報酬KPが7の倍数で発動。通常の倍率低下を125%倍率へ反転（ゲーム結果は不変）。 |
| 5 | 突然変異 | 通常召喚で重複時、1/4,096で変異。変異は各遺物IDの初回1回のみ。虹彩＋12%常時、偶数覚醒＋24%偶数時、逆境＋17%敗戦時。過去の所持品は再抽選しない。 |
| 6 | セット | 同系統の発動2個＋10%、異系統発動3個＋15%、同レア3個発動＋25%。組み合わせは一つの報酬でのみ判定。 |
| 7 | 召喚履歴 | 新規召喚操作の結果をstateに最大30件保存。最高レア、変異、特殊外観、支出を記録して演出を再生できる。古い召喚結果は復元しない。 |
| 8 | 特殊外観 | 通常召喚で1/40,000、各遺物IDの初回1回のみ。ホログラム／星紋／深淵の外観と条件なし＋3%を付与。既存アイテムは消さない。 |
| 9 | Discord速報 | 超越・古代・突然変異・特殊外観の当選を、登録済みKP獲得Webhookがある場合だけ既存投稿キューに操作IDで重複排除して通知。なければ投稿なし。 |
| 10 | プリセット | バランス・VALORANT・競馬・カジノ・株式・危険なビルドの6保存枠。保存／読込／削除は既存のKP操作トランザクション内で確定。未所持やユナイト2個以上は不可。 |
| 11 | 経済ダッシュボード | 召喚累計支出、本人の検証報酬の台帳合計、V7以降のnative総追加額、ギルド全体の検証遺物ボーナス集計。本人以外の残高・プレイ個票を表示しない。 |

## 運用上の安全性

- 遺物は原ゲームの勝敗、賭けの出目、株価、競馬の順位、Mリーグの公式結果に干渉しない。
- KP加算のゲーム内ソフト上限はV6どおり撤廃する。ただしDBの整数・残高制約は残す。
- 外部ポイント付与は実在する検証済み証憑、nativeは確定したプラスの純利益のみに対して判定する。
- D1追加表はログ専用で、元KP台帳を再集計・巻き戻し・書き換えない。
- 新規Cron、常時監視、全メンバーの毎分スキャンは追加しない。データ集計は遺物画面を開いた時に本人とギルドの集計値だけを取得する。
- V7の特殊変異・外観は再抽選しない。過去の実績や過去の召喚は勝手に増やさない。
- 既存の高レア召喚演出（スキップ・任意の効果音・prefers-reduced-motion）は維持する。

## データの構造

- `relics.summonHistory` 最大30件。
- `relics.nativeEffects` 最大30件。
- `relics.presets` 最大6個。
- `relics.items[id].mutation` / `foil` は各IDの初回当選のみ。
- `relic_effect_logs` は検証済みボーナスのみ、発生証憑ごとに一意。本人の履歴上位30件を画面に表示する。
- `kp_ledger` が最終的な本人KP残高の根拠だ。表示用ログを失っても報酬は失わない。

## フォローアップ候補

V7の評価指標は、特定のビルド集中率、変異・特殊外観の取得人数、装備切替回数、遺物KPの週次純増である。急激な経済インフレが観測された場合は、記録を調べてからゲーム内のバランスを見直す。過去の報酬を没収する仕様は含めない。
