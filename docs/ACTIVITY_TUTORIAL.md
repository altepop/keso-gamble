# KESO PLAY｜初めての人のための遊び方ガイド

Activity内の右下「**？ 遊び方**」で、この説明を開ける。初めてホームに来た人には5ステップのチュートリアルを表示する。説明を読むだけではKPは消費されず、「この画面を開く」は画面移動だけを行う。

> **最初に大事なこと**：KPは現金と交換できないゲーム内ポイント。本番口座と端末デモのKPは別。報酬、購入上限、倍率、取引制限は変わるため、必ず現在のActivity画面に表示された条件を優先する。

## 初回起動の5ステップ

1. **ようこそ、KESO PLAYへ** — 仲間と一緒にKPを稼ぎ、競馬・カジノ・株で増やし、指名・馬主・遺物などに使うゲームだ。
2. **KPはゲーム内のお金** — KPはゲーム内のポイント。増えることも減ることもある。現実のお金とは交換できず、デモと本番の口座も別だ。
3. **まずは「稼ぐ」を見る** — 試合、通話、VCT QUIZ、Steamなどの条件を満たすと報酬を得られる。どの方法が自分に合うか確認しよう。
4. **勝負と使い道がある** — 遊ぶ：競馬・Mリーグ・カジノ・株。使う：指名・馬主・高級品・遺物。まずは少額から仕組みを把握しよう。
5. **どこでも「？ 遊び方」** — ガイドは何度でも開ける。各ページの手順と注意点を読んで、そのゲームの画面へ移動できる。

## まず最初に

### まずはここから

KESO PLAYはDiscordの仲間と共通のKPを稼ぎ、勝負や指名、コレクションに使うゲームだ。最初は「稼ぐ」から始めると分かりやすい。

1. タイトルから「はじめる／つづける」を押す。Discord Activityなら基本的に本人のKP口座へ接続される。
2. 画面下部の「稼ぐ・遊ぶ・使う・資産」を確認する。ホームの大きなメニューからも移動できる。
3. まず「稼ぐ」で報酬の条件を確認し、受け取ったKPで好きなモードを試す。
4. 迷ったら画面右下の「？ 遊び方」を押す。今開いているモードの説明が表示される。

**コツ**：ガイドを読むだけではKPを使わない。別のゲームへ行くボタンも決済操作ではない。

**注意**：
- KPはゲーム内ポイントで、現金や現実の商品とは交換できない。
- 初めての人は大きな金額を賭ける前に、そのゲームの損失条件を確認する。

### KP・本番口座・デモ

KPはゲーム内の共通ポイント。本番口座と「デモで試す」のポイントは別物だ。

1. Discord Activityから起動し、本人の口座に自動接続できたか確認する。
2. 本番口座なら試合報酬、株、馬、カジノなどの取引・記録がサーバーに保存される。
3. デモは操作を試すための端末内データ。本番のKPは増えない。
4. 残高や株式評価額、入出金の状況は「資産」で確認する。

**コツ**：残高がマイナス相当になったときの「借KP」は自動返済や利用制限がある。資産画面の表示を確認しよう。

**注意**：
- 接続中・通信結果確認待ちでは操作を連打せず、残高と履歴の確定を待つ。
- ページを閉じても本番のサーバー口座は基本的に保持されるが、デモの保存状況は端末による。

### ホーム

最初に戻る場所。残高、指令、各ゲームへの入口がまとまっている。

1. 上段の保有KPと発令中の指令件数を見る。
2. 「稼ぐ」「競馬」「カジノ」「株」「指名」「馬主」「高級品」「遺物」から行きたい場所を選ぶ。
3. 試合やコミュニティの状況は表示されている欄を開いて確認する。

**コツ**：迷ったらホームに戻り、何がしたいかで入口を選ぶ。

**注意**：
- ホームに表示されるKPは、デモと本番口座で異なる。

## KPを稼ぐ

### 稼ぐ：試合・通話・QUIZ・Steam

KPを獲得する中心メニュー。VALORANTの戦績、通話、外部ゲームの達成状況などで報酬を得る。

1. 画面下の「稼ぐ」を開き、今の報酬表や参加条件を確認する。
2. VALORANTでは対象試合の結果に応じてKPが増減し、速報や口座への反映に少し時間がかかる場合がある。
3. 通話・VCT QUIZ・KESO LOOP・Steam連携などは、各欄に表示された条件を満たす。
4. 支給されたKPは「資産」で確認。未反映なら重複申請せず、入出金履歴を見直す。

**コツ**：VCT QUIZやKESO LOOPは専用画面へ移動できる。Steamは対象実績や連携状況、日次上限に注意。

**注意**：
- 勝敗や成績によって減額されるモードがある。
- デモの「確認して支給」は実際の戦績の検証ではない。
- 毎日の上限・例外条件・報酬額は変わる場合があるので、実際の稼ぐ画面の最新表示を優先する。

### Discord通話で稼ぐ

対象サーバーの通常ボイスチャンネルに参加した時間に応じて、KPを受け取る。Activityを開いていなくても対象になる。

1. Discordの対象サーバーで通常のボイスチャンネルに参加する。
2. 「稼ぐ」画面の「通話で稼ぐ」で、計測中かどうか・今日の受取額を確認する。
3. 5分単位でKPが加算される。上限に達したら、翌日の更新を待つ。

**コツ**：ミュート中や1人での滞在も対象だ。今日の上限と単位報酬は稼ぐ画面で分かる。

**注意**：
- Bot、AFK、ステージチャンネルは対象外。
- 接続準備中・監視再接続中と表示されている場合は加算状況を確認する。
- 1日の上限は日本時間の朝9時更新。

### VALORANTの試合で稼ぐ

コンペ・アンレ・スパイクラッシュなどの対象試合結果を、アカンbotが確認してKPへ反映する。

1. Discordの自分のゲームアカウントが連携対象か確認する。
2. 対象のVALORANTモードでプレイする。勝敗や成績が確定したら速報を確認する。
3. 「稼ぐ」でモード別報酬・特殊ルールを読み、入出金履歴で増減を確認する。

**コツ**：勝つと増えるモードだけではなく、成績ボーナスやランダム補正のあるモードもある。

**注意**：
- 負け・味方最下位・一部抽選でKPが減る場合がある。
- 同一試合の報酬は重複しない。反映には数分かかる場合がある。
- 指名達成条件は通常の試合報酬とは別に判定される。

### スパイクラッシュ・ロール覚醒

スパイクラッシュでは試合履歴やロールの覚醒状態によって、KPの受取が変わる。

1. スパイクラッシュをプレイし、まず自分のロール別進捗を確認する。
2. Discordで「/spike status」を使い、条件の達成状況や現在の状態を見る。
3. ヒントが必要なら「/spike hint」の説明を読む。秘密の条件があり、すべては公開されていない。
4. 覚醒後の効果・付与された遺物の補正は、試合報酬や入出金の内訳で確認する。

**コツ**：ロールごとの条件や強化段階があり、いつでも同じKPがもらえるわけではない。

**注意**：
- 非公開の覚醒条件を外部ガイドで勝手に明かさない。
- ヒントの購入にはKPが必要な場合がある。必ずコマンドの案内を確認してから実行する。
- 報酬や補正は調整されるため、数値は最新のステータスと入出金を優先する。

### デスマ・スイフト・チーデスなど

通常のコンペ以外にもKP対象のモードがある。ただし全モードが無条件支給ではない。

1. 「稼ぐ」画面の報酬表と「細かいルール」を開く。
2. デスマッチは順位や40キル到達、K/Dなど、対象条件を確認してから挑戦する。
3. スイフトは特定の勝ち方、チーデスはキル数・K/Dなど条件付きで報酬になる。
4. 結果確定後、速報と入出金履歴で支給または減額を確認する。

**コツ**：一部モードには毎日の挑戦回数や成績条件がある。何の条件で報酬が出たかを意識しよう。

**注意**：
- 条件を満たさない試合は報酬0の場合がある。
- 負けやK/Dによって減額となるモードもある。
- カスタムマッチは現状の対象外として画面に案内されている。

### エスカレーション・特別抽選

エスカレーションの戦績には条件付き成績報酬があり、特別な大勝負抽選が発生する場合がある。

1. 対象のエスカレーションをプレイし、勝敗と成績を確定させる。
2. 「稼ぐ」の「エスカレーション・大勝負抽選」で履歴を確認する。
3. 対象の結果があれば「ルーレットを見る」で演出を再生する。
4. 試合報酬と特別抽選のKP増減は入出金履歴で確認する。

**コツ**：抽選はサーバーで一度だけ確定している。画面のルーレットは結果の表示演出だ。

**注意**：
- 大勝負では敗北時にKPが減ることがある。
- 超アンラッキーでは保有KPが大きく減るケースがある。
- 演出の再生やスキップで再抽選・重複支給は起こらない。

### VCT QUIZで稼ぐ

VALORANTの知識クイズを最後までプレイして、対象回数までKPを獲得する。

1. 「稼ぐ」→「VCT QUIZへ」を開く。
2. Discordログインで対象アカウントを接続し、好きなクイズモードを選ぶ。
3. 途中退出せず最後までプレイし、終了後に支給状況を確認する。
4. Activityの「稼ぐ」でモード別の受取済み表示や回数を確認する。

**コツ**：ランクマッチは原則1日10回、他の対象モードは1日1回。更新は朝9時だ。

**注意**：
- 途中退出・対象外の再挑戦は報酬にならない。
- 支給回数や額は各モードの画面を確認する。

### Steam実績で稼ぐ

対象の有料Steamゲームの新しい実績解除を確認してKPを得る。登録や監視設定が必要だ。

1. 「稼ぐ」→「Steam実績で稼ぐ」から公式Steamログインへ進む。
2. 帰ってきたら接続先のSteamアカウントを確認し、自分のものなら接続を確定する。
3. プロフィール・ゲーム詳細を公開し、「所持ゲームから選ぶ」で監視するゲームを選択する。
4. ゲームで新しい実績を解除し、監視状況・日次残額・入出金履歴を確認する。

**コツ**：対象は有料販売中・累計プレイ120分以上のゲーム。最大5本を同時監視でき、解除率が低い実績ほど報酬が高い。

**注意**：
- 監視開始前に解除済みだった実績は対象外。
- 無料・基本無料・無料配布中・体験版・DLCなどは対象外。
- 1日あたりの受取上限（現在の表示では全ゲーム合計5,000 KP）は翌日に繰り越さない。
- 監視・支給の有効化が準備中と表示される場合はKPが入金されない。

### KESO LOOPで稼ぐ

別ゲームのKESO LOOPで初めて到達したステージや章の進行が、条件付きのKP報酬になる。

1. 「稼ぐ」→「KESO LOOPを開く」を押す。
2. KESO LOOP内の「セーブデータ → KP報酬」でDiscordアカウントを接続する。
3. 「KP対象の進行で遊ぶ」を選び、初回突破・初回クリアを目指す。
4. KESO LOOP側の「KP報酬」で達成記録と入金状況を確認する。

**コツ**：初回達成の報酬は大きいが、各章につきDiscordアカウントごとに1回の条件だ。

**注意**：
- 端末内の通常セーブでの進行は対象外。
- 連携できていても自動入金が準備中の場合がある。
- 何度もクリアしても初回報酬が繰り返し支給されるわけではない。

### ポケモンユナイト連携

連携されたユナイトの勝敗をもとに、連勝・連敗に応じたKPが増減する。

1. 対応するDiscordアカウント・ゲームアカウントの連携状況を確認する。
2. 対象のポケモンユナイトの試合をプレイし、勝敗を確定させる。
3. 「稼ぐ」の詳細ルールと、資産または入出金履歴の「ユナイト」項目を見る。

**コツ**：連勝で報酬が増え、連敗が続くと減額が大きくなる仕様がある。上限や倍率は最新の報酬ルールを確認しよう。

**注意**：
- すべてのモード・すべての試合が対象とは限らない。
- 負けた際はKPが減ることがある。

### スカーミッシュ（2対2）

連勝報酬を受け取るか、さらに勝ち進んで増やすかを選ぶモード。

1. 2対2の対象試合で連勝し、報酬を保留する。
2. Discordの「/kp balance」で保留中の額を確認する。
3. ここで受け取るか、次の試合へ続行するかを選ぶ。
4. 続行を選んだ場合は、次の試合結果に応じて保留額が更新される。

**コツ**：負ける前に確定すればその時点の保留報酬を守れる。

**注意**：
- 続行して敗北すると保留報酬が0になる。
- 保留額が失われても口座にあるKPが直接引かれるわけではない。
- 次の試合前に受取・続行を選ぶ必要がある。

### 雀魂など外部ゲーム連携

雀魂などの外部ゲームの支給・減額も、サーバーが確認した場合はKPの入出金履歴に記録される。

1. Discordで案内されている対象ゲームとアカウント連携・報酬条件を確認する。
2. 対象の対局や試合を終了し、結果を確定させる。
3. Activityの「稼ぐ」や入出金履歴で反映状況を見る。
4. 結果が見つからない場合は、Discord側の連携・対象条件を確認する。

**コツ**：VALORANT以外の報酬も共通KPに入るため、獲得KPは競馬や遺物などでも使える。

**注意**：
- ゲームごとに集計・反映条件が異なる。
- 対象外の結果や二重報告では追加支給されない。

## 勝負して増やす

### 競馬：馬券を買って観戦

出走馬の着順を予想して馬券を購入する。レースと結果をみんなで共有できる。

1. 画面下「遊ぶ」→「競馬」を選ぶ。次の発走時刻と締切までの残り時間を見る。
2. 「単勝（1着を当てる）」や「複勝（3着以内を当てる）」など、画面にある馬券の種類を選ぶ。
3. 馬と掛け金を選び、倍率と払戻見込みを確認してから購入する。
4. 発走後はレースを観戦。終了後の着順・的中・精算を確認する。

**コツ**：出走馬やオッズ、馬場・距離などの情報を見比べるのが醍醐味だ。馬券を買わなくてもレースを見られる場面がある。

**注意**：
- 締切後の購入はできない。画面に出ている締切時刻を優先する。
- 外れれば掛け金を失う。払戻額と利益は違い、利益は払戻額から掛け金を引いた額だ。
- 購入上限は他の予想モードと合算の場合がある。最新の残額表示を確認する。
- レースの開催・不成立・結果確定の扱いは現在のゲーム画面を優先する。

### Mリーグ：ラスの選手を予想

Mリーグ公式戦の各半荘で、4着（ラス）になる選手を予想する。

1. 「遊ぶ」→「Mリーグ」を選び、対象の対局と選手を確認する。
2. 「ラスになりそうな選手」を1人選ぶ。
3. 掛け金を入力し、表示された確定倍率・予想内容を見直す。
4. 確認画面で購入を確定。対局結果の反映後に的中・払戻を確認する。

**コツ**：100 KP以上、100 KP単位の入力。倍率は購入時に確定する。

**注意**：
- 1位を当てるゲームではなく、最下位（4着）を予想するゲームだ。
- 競馬との合算購入上限、販売締切、対象となる対局は画面を確認する。
- 不的中では掛け金を失う。

### カジノ：7つのゲーム

ルーレット、チンチロ、ブラックジャック、マインズ、スロット、ポーカー、バカラから選ぶ。

1. 「遊ぶ」→「カジノ」を開く。
2. 画面上のゲーム切替ボタンから遊びたいものを選ぶ。
3. 各ゲームの賭け金と操作方法を確認する。
4. 結果と差し引きKPを確認してから次の勝負へ進む。

**コツ**：初心者はルーレットの赤・黒、またはバカラから始めると操作を覚えやすい。

**注意**：
- 見た目の倍率は、多くの場合「掛け金込みの払戻倍率」だ。
- チンチロのように掛け金より大きく損をする場合がある。
- 連打で再購入しないよう、処理中は画面の結果を確認する。

### 株：架空銘柄の売買

KESO TOWN内の架空株を売り買いする。全員共通の相場が動く。

1. 「遊ぶ」→「株」を開き、銘柄一覧と値動きを確認する。
2. 気になる銘柄をタップしてチャートを読む。
3. 「買う」または「売る」を選び、銘柄と株数を入力する。
4. 手数料・支払／受取見込みを確認してから注文する。保有株と損益は「資産」で確認する。

**コツ**：本番口座では株価は共通の5分相場。条件を満たした保有株に配当や株主優待が付く場合がある。

**注意**：
- 株価が下落すると評価額が下がる。売買には手数料がかかる。
- 取引の数量が価格に影響する場合がある。見込み金額が変わった際は注文が止まることがある。
- 現実の株式・市場とは連動していない。

## カジノ7種

### ルーレット

0〜36のうちどの数字が出るかを予想する。赤黒や偶奇でも賭けられる。

1. 「カジノ」→「ルーレット」を選ぶ。
2. 赤／黒、奇数／偶数、1〜18／19〜36、ダズン、列、数字指定などの予想方法を選ぶ。
3. 掛け金を入力する。数字指定では盤面の数字をタップし、数字ごとに設定する。
4. 「ルーレットを回す」を押して結果と払戻を確認する。

**コツ**：赤黒・偶奇などは2倍、ダズン・列は3倍、数字指定は36倍（いずれも掛け金込み）。

**注意**：
- 0は緑色で、赤黒・偶奇などには入らない。
- 数字指定は複数選択できるが、合計掛け金に上限がある。
- 外れた賭け金は戻らない。

### チンチロ

親（KESO）とあなたがサイコロ3個で役を作って勝負する。

1. 「カジノ」→「チンチロ」を選ぶ。
2. 賭け金と手持ちKPを確認する。
3. 「サイコロを振る」を押す。親が先に振り、条件に応じてあなたの番になる。
4. ピンゾロ・ゾロ目・シゴロなどの役と、勝敗によるKP増減を見る。

**コツ**：ピンゾロは5倍、ゾロ目は3倍、シゴロは2倍の強い役だ。役の詳細はゲーム内「役と倍率」で確認できる。

**注意**：
- 最大で賭け金の5倍を失う可能性があるため、賭け金の5倍以上の所持KPが必要だ。
- 結果の演出はスキップできるが、抽選や決済はやり直されない。

### ブラックジャック

手札の合計を21に近づけ、21を超えずにディーラーに勝つカードゲーム。

1. 「カジノ」→「ブラックジャック」を選んで賭け金を入力する。
2. カードが配られたら合計点を確認する。
3. 「ヒット」で1枚引く／「スタンド」でそのまま勝負する。条件を満たす初手では「ダブル」も選べる。
4. ディーラーの手札と比べ、勝ち・負け・引き分けを確認する。

**コツ**：最初の2枚で21になるブラックジャックは通常の勝ちより高い2.5倍の払戻だ。

**注意**：
- 21を超えたらバーストで負ける。
- ダブルは追加で賭け金を出す操作。残高と効果を確かめてから押す。

### マインズ

5×5の盤面で地雷を避けながら、安全なマスを開くほど払戻倍率が上がる。

1. 「カジノ」→「マインズ」を選ぶ。
2. 掛け金と地雷の個数を決めて「はじめる」。
3. まだ開いていないマスを1個ずつタップする。安全なら倍率が上がる。
4. 好きなタイミングで「降りる」を押すと、その倍率で払戻が確定する。

**コツ**：地雷が多いほど当たりにくいが、倍率が大きくなる。まずは安全に1マス開けるところから。

**注意**：
- 地雷を1個でも踏むとその勝負の賭け金を失う。
- 次のマスを開ける前に、今の払戻額を確認すると判断しやすい。

### スロット

リールを回して絵柄を揃えるシンプルな勝負。共有ジャックポットもある。

1. 「カジノ」→「スロット」を選ぶ。
2. 賭け金を入力して「回す」を押す。
3. 止まった絵柄と配当表を確認する。
4. 本番口座では共有ジャックポットの金額・獲得条件も確認する。

**コツ**：同じ絵柄3個、または特定の組み合わせに配当がある。配当表はゲーム画面に表示される。

**注意**：
- 回すたびに賭け金を消費する。
- ジャックポット全額獲得には掛け金の条件がある。表示された条件を確認する。
- 共有ジャックポットはデモ口座では対象外だ。

### ビデオポーカー

5枚のカードから残すカードを選び、1回交換してポーカーの役を作る。

1. 「カジノ」→「ポーカー」を選ぶ。
2. 賭け金を入力し「配る」を押す。
3. 残したいカードをタップして「HOLD」にする。選ばなかったカードが交換される。
4. 「交換する」で役と払戻が確定する。

**コツ**：ジャック以上のワンペアから払戻があり、強い役ほど倍率が上がる。

**注意**：
- 交換は1回だけ。
- 役の倍率は画面の配当表を確認する。

### バカラ

プレイヤー側とバンカー側のどちらが9に近くなるか、または引き分けを予想する。

1. 「カジノ」→「バカラ」を選ぶ。
2. 賭け金を入力し、プレイヤー／バンカー／引き分けのどれかを押す。
3. 自動でカードが配られる。
4. どちらが勝ったかと払戻を確認する。

**コツ**：プレイヤー2倍、バンカー1.95倍、引き分け9倍の払戻（掛け金込み）。

**注意**：
- プレイヤー／バンカーに賭けて引き分けになった場合は返金となる。
- 選んだ側が負ければ掛け金を失う。

## KPを使う

### 指名：仲間に指令を出す

KPを使って特定のメンバーにゲームの課題を出す機能。

1. 「使う」→「指名」を開く。
2. 対象のメンバーを選び、指令の内容を選ぶ。
3. 必要KP・達成条件を読み、発令ボタンを押す。
4. 発令中の指令と達成状況を同じ画面で確認する。

**コツ**：ゲームモードやソロ判定など、指令ごとに細かい達成条件がある。発令前に必ず確認する。

**注意**：
- 指令の発令時点でKPを消費し、達成されても発令費用は返ってこない。
- 同じ相手への未達成指令は原則1件まで。
- 本番口座では対象者に通知されるが、デモ指令は外部に送信されない。

### 馬主：自分の馬を育てる

馬を迎え入れ、出走・賞金・二つ名などを楽しむモード。

1. 「使う」→「馬主」を開く。
2. ボックスや購入条件を確認し、迎え入れる馬を選ぶ。
3. 保有馬の出走・成績・賞金などを確認する。
4. 必要に応じて馬の売却・引退などの管理を行う。

**コツ**：競馬の「馬券を買う」と、馬主として「馬を持つ」は別の機能だ。

**注意**：
- 馬の購入・売却にはKPの増減が伴う。確定前に対象馬と金額を見直す。
- 馬主機能は本番口座が必要だ。

### 高級品：特別な使い道

貯めたKPで称号・冠レースなど、特別な効果を持つ高級品を購入する。

1. 「使う」→「高級品」を開く。
2. 商品一覧で価格・条件・効果を読む。
3. 購入する商品を選び、対象メンバーや入力項目があれば指定する。
4. 最終確認で支払KPと内容を見直してから確定する。

**コツ**：高級品は見た目の演出やサーバー内の遊びを盛り上げる長期目標になる。

**注意**：
- デモでは商品一覧のプレビューのみで、本番KPを使う購入はできない。
- 購入確認は取り消しではなく支払い直前の最終確認。意図しない購入を避けよう。

### 遺物：図鑑で装備・効果を試算

召喚や限定報酬で遺物を集め、図鑑から4枠に装備する。装備後の追加KPはビルドで試算できる。

1. 「使う」→「遺物」を開く。上部には「図鑑」「ビルド・試算」「召喚」「欠片・交換所」「記録・限定」がある。
2. 「召喚」で遺物を集める。1回200KPで、レアごとの排出率も確認できる。Steam・ユナイト限定遺物は「記録・限定」から獲得する。
3. 「図鑑」で効果を比べ、先に装備する枠（1〜4）を選ぶ。遺物カードの「効果の詳細・装備」を開き、「指定枠に装備」を押す。
4. 「ビルド・試算」で現在の4枠と追加KPを確認する。おまかせ装備、プリセットの保存・切替もここで行える。
5. 被った通常遺物は「欠片・交換所」で欠片に変え、伝説以下の遺物やMy馬引換券と交換できる。召喚履歴や限定遺物は「記録・限定」で確認する。

**コツ**：基本は図鑑で比較して手動装備。迷ったら「ビルド・試算」のおまかせ装備を使い、モード別の実効倍率を比べよう。

**注意**：
- 召喚は1回200 KP。10連・100連・1000連は合計額を確かめてから押す。
- レアリティごとの排出率は異なり、高レア確定の天井がないものもある。
- 赤い「代償」を持つ遺物は、ほかの効果を弱める場合がある。図鑑での所持だけでは発動せず、装備したうえで各効果の条件を満たす必要がある。

## 口座・確認

### 資産：残高・株・履歴を見る

持っているKPと株、入出金・口座状態を確認する画面。

1. 画面下の「資産」を開く。
2. 保有KP・株式評価額・純資産を確認する。
3. 保有株と取引履歴、利用可能な履歴・口座情報を確認する。
4. 借KPや通信確認待ちなどの表示があれば、状況を確かめる。

**コツ**：カジノや株で増減した額が分からなくなったら、まず資産と各モードの履歴を確認する。

**注意**：
- 借KPが残っていると、一部の購入や勝負が制限される。
- デモの「テストKP補充」は実際にKPを稼ぐ方法ではない。
