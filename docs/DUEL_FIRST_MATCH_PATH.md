# 決闘を始めるまでの最短手順（第5フェーズ）

この文書は既存のUIで案内される入口を整理したもので、実際のDiscord接続やKPの代行をしない。

1. KESO PLAYの「勝負」から決闘を探す。最初は決闘デモで6種目の操作を試せる。
2. ゲームを選び、画面にある「勝利条件」「最初にすること」「覚えておくこと」を開く。
3. 相手と賭けKPの表示を確認してから招待する。招待操作と対戦成立は別である。
4. 画面の「招待」「対戦」「結果・再戦」の段階表示を確認する。
5. 通信状態・更新中・前回操作未確認の場合は、直前の操作を続けて送らず、画面の確認導線を利用する。
6. 終了後は結果を確認し、再戦のフォーム内容が正しいか見直す。

## 迷ったとき
- ルールが分からない：ゲーム別の開閉式ガイドを見る。
- 相手がいない：相手の候補・読み込み状態を確認し、画面の「更新」を使う。
- 操作が反映されない：確定前の状態から成功を推定しない。
- 再戦：再戦の準備だけでは招待もKP取引も行われない。

この案内はサーバー確定済みの情報に依拠する。相手の秘密情報を推測・表示しない。表示時間の計測値は端末内の操作から確定表示までの参考時間であり、相手への反映速度や1秒以内の保証ではない。
