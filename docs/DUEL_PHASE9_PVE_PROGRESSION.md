# ロードマップA 第9フェーズ P9.4d：PvE確定終局と熟練度
- P9.4aの6種目CPU合法手エンジン・P9.4bの認証付きD1セッションに加え、サーバー確定の自然終局だけをPvE熟練度に接続する。
- 認証済みユーザーの操作に対しサーバーCPUが応答し、D1のPvEアクショントリガーが`human→finished`へ更新したとき、アクションの`session_id`・手番バージョン・時刻・盤面・勝者・人間/CPU操作数が一致する場合だけ受取を発行する。
- 一意キー`guild,match_id,user,mode,game`で、リロードや再送による二重熟練度を防ぐ。熟練度・戦績の更新も同一SQLiteトランザクションで確定し、失敗時は操作とともにロールバックする。
- 6種目に独立したPvE進行記録。P9.3と同じく暫定進行ポイントはサーバー確認済みの勝利1回につき1、敗北と引き分けは0。これは実力レーティングではない。両モードの戦績を分けて保存する。
- 既存のブラウザ練習はサーバーPvEセッションIDを持たず、受取を作れない。相手の秘密を公開前に返さない。KP、遺物、報酬はP9.5まで付与しない。
- 暫定ポイントの強さと攻略段階の倍率、各種報酬の上限・同一相手の周回対策はP9.5の経済テストまで固定しない。第9フェーズ完成宣言はP9.5の完了後のみ。
