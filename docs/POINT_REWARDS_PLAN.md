# 試合KPの運用

2026-10-27: ユーザーの「それで有効まで」に基づき、自動支給とサーバー口座を接続。設定は `services/valorant-results/kp-policy.json`。開始時刻は初回起動時にD1へ一度だけ保存し、再配置で変更しない。

コンペ指名は2,500 KP。1勝900 KPなので3勝で2,700 KP、指名後は200 KP残る。連勝の追加手当はなく、間に負けても獲得KPは残る。

| コンペ | 300 | 600 | 900 |
| アンレ | 200 | 100 | 300 |

負け・引き分け・勝敗未確認は参加分のみ。ゲーム全体が完了した、対応済みの本人の履歴だけを対象にする。通常アンレも収集し、/death予約の有無とは独立して報酬を付ける。

## 保留中

- デスマッチ: 本人が完走した場合のみ支給する方針。Henrik v4の `session_playtime_in_ms` は経過時間で、本人の完走・途中退出の証明にはならない。現時点では全件支給保留。
- カスタム・未知のモード: 報酬ルール未確定のため保留。速報の監視対象からは外さない。
- Steam実績: 検証元と支給を未接続。本番のSteam指名もまだ発行しない。
- 通話: 未有効。5分で5 KP・日240 KPは提案値。既存のHTTP型Workerには入退室を受けるGatewayがなく、Activityの表示時間から通話を推定しない。音声収集・録音は不要。

Henrik公式仕様: https://api.henrikdev.xyz/openapi.json

## 本人確認と口座

Discordの署名確認済み `/valo status` に、本人だけが読める接続コードと残高を表示する。コードは10分・1回限り。Activityのタイトルでコードを貼り付けて接続する。接続情報はデモ資産と別のlocalStorageに保存し、Activityを閉じても同じ端末・同じ保存領域では自動復帰する。サーバーのセッション期限は接続から30日。期限切れ・端末変更・保存データ削除後は再接続する。保存が禁止されている環境は一時保存へ切り替え、その旨を表示する。未確認の決済IDはタブごとのsessionStorageに保持し、別タブの操作で上書きしない。サーバーにはコードとセッションのハッシュだけを保存。ブラウザーのuserId指定で他人の口座を読めない。

4人の対応表は既存Worker専用RSA公開鍵でAESキーを暗号化した封筒 `kp-bootstrap.encrypted.json` に入れる。秘密鍵はWorker secretのみに保持。公開リポジトリ・ログ・artifactへ平文の対応表を出さない。

新しい口座は0 KP。デモの10,000 KP、給与、手動の「デモ確認」を本番へ取り込まない。本番の試合支給は試合ID＋PUUID＋サーバーIDの一意キーで一度だけ。旧 `rewards-config.json` と `reward_*` 基盤は未接続のまま保持し、新しい `kp_*` テーブルを追加する。旧設定のenabled=falseは新KP運用を無効にするスイッチではない。

台帳のINSERTトリガーが同じSQLite文内で残高を更新し、残高不足・整数範囲超過は操作全体をロールバックする。支給失敗は `kp_inbox` から再試行。速報の投稿失敗とは独立し、確定した入金だけを速報へ追記する。APIの再取得でも二重入金しない。

## Activityと決済

残高・報酬履歴・架空株・ルーレット・指名の決済はサーバー側で確定する。抽選結果と残高をブラウザーから提出させない。操作IDを送信前に保存し、応答喪失・再読込後も同じIDで確認する。

コンペ指名2,500 KP、アンレ指名1,500 KP。自分自身・未登録者への指名を拒否し、相手1人につき未達成1件まで。指名は双方のActivityとDiscordに表示。発令後に始まった指定モードの完了試合で達成となり、返金しない。相手のPCやゲームを遠隔操作する機能ではない。

Discord内の通信には既存VCT QUIZのActivities → URL Mappingsへ次の1行を追加する。既存の `/` とクイズOAuthを削除しない。

| Prefix | Target |
| --- | --- |
| `/kp-api` | `valorant-results.tealeaforest.workers.dev` |

通常ブラウザーの https://altepop.github.io/keso-gamble/ はWorkerへ直接接続する。Discord内は `/.proxy/kp-api/api/kp/…` を使用。接続失敗時にデモ残高へ自動で切り替えない。
