## 本人確認と口座

Discord Activity内では公式SDKで開いた本人を確認し、KP口座へ自動接続する（OAuth2 Client Secretのサーバー設定が必要）。初回はDiscordのidentify許可画面が出る場合がある。通常ブラウザー・設定前・自動接続失敗時には、署名確認済み `/valo status` の本人限定接続コードも使える。コードは10分・1回限り。Activityのタイトルでコードを貼り付けて接続する。接続情報はデモ資産と別のlocalStorageに保存し、Activityを閉じても同じ端末・同じ保存領域では自動復帰する。サーバーの接続期限はなし。`kp_sessions.expires=-1` で無期限を表し、本人の「接続を解除」で該当セッションをサーバーから削除する。有効な旧30日セッションは次の本人確認時に期限なしへ移行するが、既に期限切れ・解除済みのセッションは復活させない。端末変更・保存データ削除・接続解除後は再接続する。保存が禁止されている環境は一時保存へ切り替え、その旨を表示する。未確認の決済IDはタブごとのsessionStorageに保持し、別タブの操作で上書きしない。サーバーにはコードとセッションのハッシュだけを保存。ブラウザーのuserId指定で他人の口座を読めない。

4人の対応表は既存Worker専用RSA公開鍵でAESキーを暗号化した封筒 `kp-bootstrap.encrypted.json` に入れる。秘密鍵はWorker secretのみに保持。公開リポジトリ・ログ・artifactへ平文の対応表を出さない。

新しい口座は0 KP。デモの10,000 KP、給与、手動の「デモ確認」を本番へ取り込まない。本番の試合支給は試合ID＋PUUID＋サーバーIDの一意キーで一度だけ。旧 `rewards-config.json` と `reward_*` 基盤は未接続のまま保持し、新しい `kp_*` テーブルを追加する。旧設定のenabled=falseは新KP運用を無効にするスイッチではない。

台帳のINSERTトリガーが同じSQLite文内で残高を更新し、残高不足・整数範囲超過は操作全体をロールバックする。支給失敗は `kp_inbox` から再試行。速報の投稿失敗とは独立し、確定した入金だけを速報へ追記する。APIの再取得でも二重入金しない。

コンペ指名8,000 KP、アンレ指名2,500 KP（ソロコンペ 50,000、ソロデスアンレ 60,000）。自分自身・未登録者への指名を拒否し、相手1人につき未達成1件まで。指名は双方のActivityとDiscordに表示。発令後に始まった指定モードの完了試合で達成となり、返金しない。相手のPCやゲームを遠隔操作する機能ではない。

| Prefix | Target |

## 借KP（払えないマイナス）
- 財布は0で止まる。引ききれなかった分は **借KP** として残る（VALORANTの負け・最下位・降格、雀魂のラス、ユナイトの負け）。ユーザーの依頼「借KPという概念にしよう。1時間ごとに利子が膨らむ感じで」。
- 株・馬などに逃がしてマイナスを0で受ける抜け道をふさぐため。
- 利子：罰として、借りてから10分たった後、**10分ごとに2%**（切り上げ・複利）。1時間で約1.13倍、3時間で約1.43倍、12時間で約4.3倍、1日で約17倍。`kp-policy.json` の `debt`（`intervalMinutes`・`interestPercent`）。2026-10-28 にオーナーの依頼「10分ごとでいいし、少し過酷にしていい。罰としてでいい」で、毎時1%から変更。
- 返済：入ったKP（試合・通話・賞金・株や馬の売却など）から毎分自動で返す。台帳の種類は `debt`（/kp では「借KP返済」）。
- 借KPがある間は、KPを賭ける・使う操作（株の購入・馬・馬券・カジノ・高級品・指名）をできない。結果を見てから止めると勝った時だけ通ってしまうので、操作の種類で抽選の前に止める。売る・ブラックジャックの途中の手を終えるのはできる。
- 手動回収（/kpgrant のマイナス）は今までどおり残高まで（借KPにしない）。
- 導入前のマイナスはさかのぼらない。

## カジノ（チンチロ・ブラックジャック）
- 2026-10-28 ユーザーの依頼「一旦チンチロとブラックジャックかな」。ルールとUIは `js/casino.js`・`js/casino-view.js`、本番の抽選はサーバー（`operateKp` の `chinchiro`・`bj-*`、暗号学的乱数）。
- 賭け金は 100〜20,000 KP。
- チンチロ：親（KESO）が先に振る。親のピンゾロ5倍・ゾロ目3倍・シゴロ2倍は子の負け、ヒフミ2倍・目なし1倍は子の勝ち。親が目なら子が最大3回振り、子の役（同じ倍率）か目の大小で決着。最大5倍負けるので、所持KPは賭け金の5倍以上必要。子の期待値は約 −1%。
- ブラックジャック：毎回52枚から引く（無限デッキ）。ディーラーの2枚目はプレイヤーが止めた後に引く（ホールカードなし）ので、隠す情報をサーバーに持たない。ソフト17で止まる。BJは3:2、ダブルは最初の2枚だけ、スプリットなし。ディーラーBJならダブルで足した分は返す。基本戦略に近い打ち方で期待値は約 −2%。
- 大きな場面（チンチロのピンゾロ、1,000 KP以上のナチュラル、±5,000 KP以上）は稼ぎchに流す。
- 借KPがある間は賭けられない（抽選の前に操作の種類で止める）。ブラックジャックの途中の手を終える「ヒット」「スタンド」だけは通す。
