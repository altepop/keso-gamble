# KESO DUEL ロードマップA — Phase 11/12 実装分割1（2026-11-22）

本変更はロードマップAのPhase 11「ゲームそのものの拡張」とPhase 12「長期運営システム」の**第一分割**であり、各フェーズ全体の完了ではない。

## Phase 11: 日替わり６種目CPUチャレンジ（実装）
- 認証済み既存CPU戦APIのPOST操作 `daily-preview` でJSTの日替わり種目・難易度（既存 easy / normal / strong）を取得する。プレビューではD1読み書きなし。
- POST `daily` にUUIDの `requestId` を付けると、サーバーがその日のゲーム・難易度を決定し、従来のサーバー権威PvEセッションを開始する。クライアント指定のゲーム・難易度は採用しない。既存 `move` / `get` をそのまま利用。
- 既存のセッション上限、秘密情報保護、重複操作防止、確定結果、フェーズ9報酬ポリシーを維持し、日替わりボーナスKPは新設しない。
- ６種目すべてを巡回する。既存UIへの日替わり案内・専用メニューの組込み、ランキング、新種目そのものの追加は**未実装**であり、Phase 11全体は未完了。

## Phase 12: 長期運営の読み取り専用監査（実装）
- `duelOperationsAudit` は明示のギルドIDに限り、90日を超える終了済みPvE/PvPの件数と進行中件数を集計して返す。対戦内容・秘密の手札・個人ID・KP台帳を返さない。
- `deletionAuthorized:false` を明示し、SQLはSELECTのみ。**自動削除、課金、KP補正、設定変更は行わない。**
- 現状は内部の監査関数・単体テストであり、定期実行・管理者向け画面・保持期間変更・削除の運用承認は未実装。必要なときは別途監査結果・影響・復元可能性を確認する。
- 既存の記録保存義務・請求や対局の照合・既存の会計台帳を勝手に期限付き削除の対象としない。
