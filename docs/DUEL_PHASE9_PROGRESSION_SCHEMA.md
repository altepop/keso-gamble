# 第9フェーズ P9.2：決闘専用D1永続化の基盤
P9.1の検証済み進行イベントの契約に続き、**決闘専用の**2表と2索引を定義する。既存KP・コーチ・D1運用タスクのテーブルや処理は変更しない。

- kp_duel_mode_skill: guild・user・PvE/PvP・6種目の複合キーで独立した熟練度・戦績を保持する。
- kp_duel_progress_receipts: 試合・利用者・モード・種目で一意の受取記録を持ち、同じ試合の二重発行を防ぐ。
- 照会索引: 人物別直近履歴、PvPの同一相手対戦履歴へのアクセスを軽くする。
- DB生成は後続の信頼されたサーバー経路からのみ呼び出す。**本PR単体では本番D1に何も書かず、熟練度・KP・遺物も付与しない。**
- 非公開情報は表に保存しない。スキル値上限・勝敗時の増減量・KP/ドロップ率は経済テストが済むまで確定値を置かない。
- 後続P9.3は、サーバー確認済みの自然な終局との取引内連携、冪等性、同一相手の報酬抑制、10人規模のD1行数・負荷計測を伴う。
- 後続P9.4は、ブラウザCPU練習と切り分けたサーバー権威のPvE対戦、隠し情報を表示しないCPU意思決定を扱う。
P9.2のCI・統合成功は第9フェーズ全体の完了を意味しない。
