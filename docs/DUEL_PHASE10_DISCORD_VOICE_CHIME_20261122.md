# フェーズ10 — Discord通話での決闘確定演出音（2026-11-22）

## 承認・実装範囲
2026-11-22のユーザー決定により、決闘の実音再生とDiscordボイスチャンネルへの音声送信は承認済みである。従前の未承認マトリクスより本決定を優先する。

本PRでは**サーバーで確定した決闘開始・終了のみ**について、専用の0.4秒の低音量オリジナル電子チャイム（48kHz / 16bit / ステレオ）を既存のKESO PLAY MUSIC Nodeボットで鳴らす。外部著作権音源や動画プラットフォームにアクセスしない。

- Cloudflare WorkerのD1確定操作後に発行された通知だけを対象とし、状態は開始（`active`・version1）または終了（`finished`・version2以上）に限定する。
- Workerの既存`MUSIC_VOICE_URL`および`MUSIC_BRIDGE_TOKEN`のみを使う。外部提供URL、別ギルド、未認可の呼出しは拒否する。
- Node側の`/v1/duel-cue`は既存共通トークンにより認証し、ギルド・試合ID・version・イベント種類を検証する。キー`guild:matchId:version:kind`で15分間冪等に処理する。
- **現在KESO PLAY MUSICボットが接続中のVC内のみ**を対象とし、非接続時・無人時は送信を省略。別VCへ勝手に参加しない。音楽再生中は短い通知の間だけ一時停止し、既存の曲・再生位置・キューを復元する。
- 通知は既存の決闘SSEヒントと独立であり、失敗や音声サービスの停止は対局、KP精算、遺物報酬、通知元DB書込を巻き戻さない。
- このPRは音声の送り先が設定済みで既存ボットが実際にVC接続している場合の**送信経路**の追加である。Node音声サービスの本番デプロイ、通話中に実際の人の端末で聞こえること、音質・途切れ・復元動作は実機で未確認であり、実際に確認するまで「配備済み」「実音声確認済み」とは宣言しない。

## 品質ゲート
