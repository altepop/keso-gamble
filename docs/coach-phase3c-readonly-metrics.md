# KESO COACH Phase 3-C — 同一パーティ確定試合の読み取り専用指標

## 今回実装する範囲

- `coach/team-metrics.js` は、すでに取得・本人確認・認可した競技試合ロスター最大250行を、**外部通信・D1書込なし**で集計する純粋関数です。
- `coach/team-metrics-view.js` は、認可済みの安全な集計DTOのみ受け取る読み取り専用カードです。外部通信、端末保存、投稿やKP付与の操作はありません。DOMへは `textContent` のみを書き込みます。
- 同一試合、同じBlue/Red側、異なる同意済みDiscord所有者2人以上、さらに**両者の空でないparty_idが完全一致**する試合だけ対象にします。同じ5人チームであっても別パーティの試合は除外します。
- 勝率は勝敗確定試合数で、K/Dは有効なキル合計÷デス合計で計算します。0分母と不明勝敗はnull、評価する情報がなければ「まだ分かりません」。トレード距離はPhase 4のため「評価範囲外」です。
- マップ別内訳、エージェント別の参加者・試合数、期間、除外理由・件数と上限を返します。生PUUID・Discord所有者ID・match ID・party_idは出力DTOに含めません。

## 認可・接続上の残条件

**今回の計算関数をHTTP APIに公開してはいけません。** Phase 3-B #641 は同意を反映した純粋な共有射影の実装です。D1上での参加・退出・個別の集計同意・version CAS・毎要求の本人所有者確認と、認可済みのロスター取得APIがまだ実装されていません。これらを通さず画面へ接続すると他人の戦績を露出するおそれがあります。

`calculateVerifiedPartyMetrics({rows,members,scope})` へ渡す `scope.authorized` や `members[].shareTeamMetrics` はクライアント入力ではなく、**サーバーが最新の認証・本人所有者・チーム・ギルド・明示同意から決定したものだけ**を使います。セッション変更時の旧データ削除と別チーム情報の404秘匿をHTTP層で検証するまで公開は保留とします。

## 合格条件と実装位置

- 自動テストは本人2名の同意、同一party_id、チーム不一致、所属反転、PUUID重複、欠損値、重複match、試合数上限、プライバシーと自動保存なしを確認します。
- 320px/375px/PC幅の実画面ブラウザ検証は、本物の認可済み画面へ接続してから行います。既存v6テンプレート・公式画像に変更を加えません。
- 未計測のD1 read性能、7マップ全取得、認証済み実ユーザー2名の試験を完了と報告しません。Phase 3-DのチームPDCA・Discord通知も範囲外です。
