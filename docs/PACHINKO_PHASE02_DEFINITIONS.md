# パチンコ Phase 02 機種・盤面・演出の定義

[マスター計画](PACHINKO_MASTER_PLAN.md) の PK-R02・PK-R15 と T01・T12 のうち、静的な定義とバージョン解決を扱います。機種、盤面、演出、素材台帳は独立したJSONです。今回は検証用の定義のみで、機種の公開状態は `fixture` に限定します。確率、賞球、交換比率はテスト用の値です。

| 項目 | 単位・形式 |
| --- | --- |
| 座標と半径 | 正の幅・高さと整数µm。左上が原点で右・下が正方向。円は盤内に収まること。盤面オブジェクトのIDは種類をまたいで一意。 |
| 発射と物理 | 左右の発射位置、固定ステップ（µs）、玉半径（µm）、操作の段階数、同時玉数、残存時間（ms）。衝突形状や材質係数の詳細は物理PoCで追加検証。 |
| 確率と交換 | 整数の分子・分母。確率は0以上1以下。交換単位はKP/玉。端数は切り捨てと記録し、計算は精算実装で扱う。 |
| 状態と上限 | 保留数、時短・STの回転数、ラウンド数・時間（ms）・入賞上限、整数KPと整数玉の上限。遷移ルールと確定順はPhase 03で追加。 |
| 演出 | 登録済みの対象、許可されたプロパティと補間、昇順の時刻（ms）。不透明度・光量は千分率、回転は千分の一度。軽量版などの参照先は同じ結果クラスを扱う。 |
| 素材 | リポジトリ内の相対パス、SHA-256、バイト数、出典・ライセンス・クレジット・同意状態。今回は空の台帳。実ファイルのハッシュ照合や権利確認は素材採用時に別途行う。 |

全定義は `schemaVersion`、`id`、`version` を持ちます。未知のフィールド、必須項目の欠損、範囲外、未知の参照はフィールド名を含むエラーで拒否します。nullは代替参照の使用なしを表す場合だけ認めます。

セッションは4定義のIDと版を保持する前提です。カタログから一致する版を解決し、存在しない旧版と版の混在を明示的に拒否します。内容を変更する場合は定義の版を上げます。将来のschema改訂では既存の検証器と定義を残すか、互換性を検証した移行を用意します。ここで検証する旧版復元の範囲は、静的定義の再取得です。

検証は `node --test services/valorant-results/test/pachinko-definitions.test.mjs` です。既存画面、Worker、KP、D1の本番コードに接続する変更は後続フェーズで扱います。
