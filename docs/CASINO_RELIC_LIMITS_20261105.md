# カジノ限定：遺物によるKP増殖防止（2026-11-05）

## 適用範囲

カジノの確定利益に対する遺物ボーナスのみを制限する。対象はルーレット、チンチロ、ブラックジャック、スロット、マインズ、ビデオポーカー、バカラ。通常の勝敗・配当・掛け金・カジノの抽選やジャックポットには影響しない。VALORANT、通話、Steam実績、株、競馬、Mリーグなど他モードへの遺物効果は変更しない。

## ルール（4枠合算の「最終的な追加KP」を制限）

- 対象はサーバーが検証した**正の純利益**に限る。負け、引き分け、まだ終わっていない勝負では追加報酬なし。
- 上限 = `min(本来の遺物ボーナス, ceil(当該決済の実掛け金 × 0.005), 250 KP, 当日の残額)`。
- **1回最大250KP、1日最大500KP**。境界は日本時間9:00（UTC日付の切り替え）。
- 通常の0.5%端数は切り上げ（100KPの勝負では上限1KP）。賭け金が不明・不正なら支給0（安全側）。
- ルーレットの複数番号賭けは**37番号のうち賭けた番号の合計掛け金**。37点均等購入は純損失なので追加0。
- ブラックジャックで合法的にダブルした場合は実投入額を2倍として計算。
- 日次消費額は`relics.dailyCasinoRelic`に保持し、既存のKP操作による楽観ロック＋一意オペレーションと同じD1原子的書き込みで保存する。**追加のD1クエリや日次Cronは不要**。
- 既存所持品、遺物倍率、装備、Steam限定品の値は全て維持。カジノでは制限前の倍率が大きくても最終支給だけ絞る。
- 2026-11-05 追記：株・競馬・Mリーグにも同じ上限を適用した（[RELIC_ABUSE_REVIEW_20261105.md](RELIC_ABUSE_REVIEW_20261105.md)）。日次の枠はモードごとに別。
- 画面内の「遺物倍率無制限」は原則の説明だが、**カジノの実支給だけ特例上限あり**。

## 期待値の観点

ルーレットの本来の払い戻し率は36/37（97.3%）だ。遺物ボーナスを確定利益時の実掛け金の約0.5%に絞ると、複数番号の全カバーや高カバー戦略で簡単に期待値がプラスになることを防げる。これは将来の新遺物も一括して対象となるので、遺物固有の個別弱体化を避けられる。

他のカジノモードについては、賭け金上限と日次上限に加え、各ゲームの基礎還元率の検証が必要だ。**全ゲームの厳密な長期期待値マイナスを数学的に証明する仕様ではない**（ジャックポット等、利用者の戦略に依存）。
