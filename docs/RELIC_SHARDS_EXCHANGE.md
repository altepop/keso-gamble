# 遺物の欠片・交換所（2026-11-03）

本機能はPR #279で拡張した通常遺物と共存する。既存所持品、ID、装備、変異、特殊個体、召喚レベルを巻き戻さない。追加する通貨・引換券はゲーム内専用で、KPや現金には交換できない。

## 欠片化
- 対象：通常召喚由来の**重複2個目以降**。最後の1個を残すため、装備していてもその1個は消えない。
- Steam・ユナイト限定遺物と、存在しないIDを指定した操作は拒否。
- 1操作最大1000個。個数はサーバーの所持数で検証し、失敗時は何も更新しない。
- 特殊変異・外観はID単位の所持品データに紐づいており、欠片化では削除しない。
- 重複数が減ると重複由来の戦力強化値は現所持数に合わせて再計算する。これは意図した交換コストだ。

| レア | 余剰1個の獲得欠片 |
| --- | ---: |
| 一般 | 1 |
| 上質 | 3 |
| 希少 | 9 |
| 伝説 | 30 |
| 神話 | 80 |
| 古代 | 250 |
| 超越 | 1000 |

## 欠片を使う
通常遺物を**指名して取得**する。装備中の新規遺物を勝手に入れ替えない。所持済みの場合は所持数を1増やす。

| 対象 | 必要な欠片 |
| --- | ---: |
| 一般 | 15 |
| 上質 | 45 |
| 希少 | 130 |
| 伝説 | 450 |
| 神話・古代・超越 | 交換対象外 |
| My馬引換券 | 180 |

## My馬引換券
- 180欠片で引換券1枚。保持は最大999枚。
- 既存のMy馬ノーマルボックス（通常3000KP）を、券1枚で購入できる。**プラチナ・レジェンドなど高額ボックスには利用できない**。
- 騎乗能力の抽選は従来のノーマルボックスと同じ。引換券で得た馬の購入価格は0KP（売却益0KP）。レース賞金は通常どおり。
- 既存の馬3頭所持上限と、指令・ボックス・高級品の1日3回制限を変更しない。

## 一貫性・不正対策
- 交換操作は従来の `/api/kp/operation` を利用する。同じ操作ID・同じリクエストハッシュでの再試行は既存の回答を返すだけで二重実行しない。
- 所持数、欠片、券は `kp_state.data.relics` にあり、`kp_operations` の既存バージョン競合防止・トランザクションに含まれる。追加D1テーブル・常駐監視・Cronなし。
- UIから指定する欠片残高、引換券保有数、遺物のレア度、馬の価格を信用せず、全部サーバー状態とカタログから再判定する。
- 通常召喚の排出率・ガチャ単価200KP・召喚レベル・履歴・検証済みゲーム報酬は変更なし。
- 上記のレートは初期設定。経済データを確認して今後調整可能。保有欠片を遡って減らす処理は含まない。
