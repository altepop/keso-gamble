# Muse v6 原本との比較

| 幅 | 原本 | 移植画面 |
| --- | --- | --- |
| 375px | [原本](prototype-375.png) | [移植後](coach-375.png) |
| 1440px | [原本](prototype-1440.png) | [移植後](coach-1440.png) |

- 7画像はユーザー提供ZIPから取り出した無加工PNGです。`../v6-assets.json` にバイト数・SHA-256を保存し、ZIPの各エントリーとの完全一致を確認しました。
- 元HTMLのCSS・本文テンプレートは完全一致です。主要セレクターの余白、背景色、フォント指定、文字サイズ、行間、切り欠きなども両幅で一致しています。`comparison.json` が実行結果です。
- 移植画面はブラウザ回帰テストの人工データです。本番の本人の戦績、本人のランク、本人が実施した練習を撮影したものではありません。
- 原本のサンプルと接続データが異なるため、本文、ブロックの長さ、ページ全体の高さは異なります。未取得ランク・未取得マップ・速報の配信確認などをサンプルから捏造しません。
- Google Fontsの外部CSSは撮影環境では読み込めていません。原本と移植画面を同一条件のフォールバックで撮影し、同じ外部フォントURL・font-family指定を維持しています。指定Webフォントの実ロードまで検証したという意味ではありません。
- タイマーは停止状態、実施予定は未選択、詳細と運用操作は閉じた状態で比較しています。375px/320pxの操作回帰では認証・詳細タブ・更新・収集停止・安全コピーも別途確認しています。
