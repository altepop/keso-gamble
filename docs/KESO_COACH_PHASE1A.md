# フェーズ1-A：本人の画面と非公開の閲覧境界

[承認済み設計](KESO_COACH_PHASE1_DESIGN.md)のPR1-Aです。本人解決・本人既定の画面・全既存読取経路の閲覧境界を実装します。目標登録はPR1-B、本人が選ぶ要約共有はPR1-Cで追加します。

## 本人の決め方

- 既存KPセッションのguild/userを操作主体にします。URL・本文・localStorageの人物名に権限を与えません。
- サーバー管理の暗号化済みKP対応と、変更できないKP口座の所有者を照合します。本人に確認済みのPUUIDでレポートを選び、名前だけの一致は使用しません。
- `coach_profiles`と`coach_profile_accounts`を分離し、KPの1人1口座の制約を維持します。神戸は2アカウントを1人物として登録します。
- 初期登録は既存Cronの5分枠で独立して行います。ページ読取でプロフィールを新設せず、KP・通知・精算の成否に影響させません。同じ登録を再実行しても書込みを増やしません。
- 主アカウントのRiot ID変更は確認済みPUUIDで追跡します。別アカウントの表示名が別PUUIDへ移った場合は既存のリンクを差し替えません。
- 未登録は本人の連携案内、所有者・アカウント対応の矛盾は409です。他人を代わりに表示しません。

## アクセス制限

| 経路 | PR1-Aの動作 |
| --- | --- |
| `GET /coach/me` | 本人の人物統合レポート、本人のアカウント選択肢、本人の取得状況を返します。初回表示の唯一の取得先です。 |
| `GET /coach/member?person=…` | 本人の人物・確認済みの自分のアカウントだけ許可します。他人・不存在は同じ404で、拒否時に試合解析しません。 |
| `GET /coach/members/status` | 本人のアカウントだけの取得状況です。D1節約中も本人の状況と許可された停止操作を確認できます。 |
| `GET /coach/rounds` | 旧VDK中心の包括レスポンスを廃止し、認証済みでも410と再読込案内を返します。 |
| `GET /coach/comparison`、`GET /coach/summary` | PR1-Cまで404です。 |
| `GET /coach/directory` | 空の一覧を返します。非公開の人物一覧は返しません。 |
| 既存の収集開始・停止・補完再開 | 従来の別の運用権限を維持します。本人のプロフィールを持つだけでは操作できません。開始応答は人物名一覧ではなく件数です。 |

全経路は既存のKP認証・guild照合・参加者確認・Origin制限の後に実行します。未認証は401、不許可Originは403です。

## レポートと画面

- 解析前に自分以外のプレイヤー名・タグを除き、名前付きの同席メンバー認識を行いません。匿名のチーム・同ロールの集計と本人の指標は維持します。
- 解析結果はネストごとの固定許可リストで返します。生ロスター、PUUID、試合ID、他人の個別成績、VDKとの関係を扱う旧診断項目を外します。
- 1試合に本人の複数アカウントが同席した場合は、既存分析の曖昧性による除外を維持します。合算キルを作ったり、1試合を複数回数えたりしません。
- v6のCSS・構造テンプレート・7枚の公式アートは維持します。固定の全選手選択と旧集計の描画を除き、自分のアカウント切替だけを表示します。
- ログイン変更では古いグラフ・レポート・コピー用textarea・人物キャッシュを消します。認証世代を照合し、遅れて届いた前ユーザーの通信を描画しません。
- 目標登録と共有設定はこのPRでは有効化しません。実効の公開範囲は全員本人限定です。

## デプロイと監査

専用ensureスクリプトで2テーブルと所有者固定トリガーを追加します。旧migrationの再適用、データ削除、KP口座の所有者変更はありません。

配備後の監査は現在のguildに限定した件数だけを読み、本人対応の準備数・非公開数・所有者競合・孤立レコード・D1 rows_readを記録します。初回Cronの反映は最大330秒待ち、必要な対応が揃わなければ監査を失敗にします。ID・座標・秘密情報は公開ログへ出しません。

本番Workerの未認証4経路の401、不許可Originの403、公開済みcoach.htmlの本人既定コードと既存表示資産を確認します。任意の既存スモークセッションがあれば、その本人のAPIも確認します。**実際の別人2セッションを用意できなければ、その実機確認は未実施と記録し、成功とは報告しません。** CIでは別人・別guild・アカウント切替・後着応答の回帰テストを行います。

Henrik呼び出し・位置テーブルの読取・KP支給・通知再投稿は追加しません。認可拒否が解析より先であること、初回表示が本人だけの1リクエストであることをテストします。D1の実測rows_readは監査クエリの値であり、認証付き分析API全体の費用と混同しません。
