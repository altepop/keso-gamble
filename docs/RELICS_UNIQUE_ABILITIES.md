# KESO PLAY 遺物の固有能力（V10）

既存の通常遺物175種・代償付き8種のID/装備/所持数・効果は変更しない。レアリティごとに固有能力遺物を1種類ずつ追加し、全190種類とする。既存のレアリティ確率と1回200KPの召喚代金は変えない。各レア内の抽選対象は1種類だけ増える。

| レア | 名前 | 固有能力 |
| --- | --- | --- |
| 一般 | 欠片掘りの鑿 | 装備した状態で重複遺物を欠片化すると、1個ごとに獲得欠片＋1（KPには作用しない） |
| 上質 | 無名の残響鈴 | 検証済みのプラス報酬1件に固定＋6KP |
| 希少 | 桁を喰らう魔灯 | 確定報酬額の十進法の各桁の合計×2KP |
| 伝説 | 平方根の旅靴 | floor(sqrt(確定報酬額))×3KP |
| 神話 | 敗走者の赤い旗 | 勝利扱いでない検証済みプラス報酬に固定＋50KP |
| 古代 | 四重奏の指揮杖 | 同じ検証済み報酬でほかの装備が発動するごとに固定＋40KP（単体では0） |
| 超越 | 千里眼の凱旋門 | 元の検証済み報酬が500KP以上で固定＋250KP |

## 固有能力の設計
- 特殊な7種類は基礎倍率0%。ほかの通常遺物と同じ4枠を消費するため、構築上のトレードオフがある。
- 固定KP系の発動先は、サーバーが検証した競技ゲーム・クイズ・通話・雀魂・ユナイト・Steam・KESO LOOP・デスマッチチャレンジなどの**確定済みプラス報酬**に限定する。カジノ・株・競馬・Mリーグなど賭け/売買を含む取引系に固定KPを付与しない。
- 既存の元報酬改変なし、勝敗やランダム抽選の改変なし。既存の証憑単位の冪等支給をそのまま利用する。無報酬・負の報酬・任意のクライアント入力への補助なし。
- 小額報酬への固定KPは新しい「加算」であり、％に読み替えない。固有能力の加算結果は既存の実支給ログに「特殊効果KP」として残す。
- 固有能力遺物は重複で戦力が育つが、％効果に化けないよう、変異/特殊外観の抽選の対象にはしない。既存の遺物の変異/外観ルールは維持する。
- 装備中の「欠片掘りの鑿」は、`relic-recycle` のサーバー内計算でのみ判定する。画面からの改ざんや二重実行は既存のKP操作冪等化が拒否する。
- D1テーブル・インデックス・cron・スキャンは増やさない。既存状態内の装備とレリック定義だけで計算する。
- ユナイトやSteam限定遺物の取得/利用条件を変更しない。

## 確認事項
ゲームの報酬を繰り返してよい数・検証方法は既存のゲーム側の仕様に従う。追加KPは受け取った実証憑から1回のみであり、賭け金の購入や架空の結果から発生しない。
