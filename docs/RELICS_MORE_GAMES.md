# 遺物：雀魂・ユナイト・Steam・KESO LOOP・デスマッチ一発勝負（2026-11-03）

オーナー指示「遺物が効かないゲームにも、しっかり遺物を作って」。

- 通常召喚に 5ゲーム × 7レア = **35種** を追加（通常175種＋代償8種 = 183種）。既存の ID・所持数・装備は変わらない（名前表の末尾に追加）。
- 各レア内は全25系統から等確率。超越などの排出率（レア度ごとの確率）は変えていない。
- 効くタイミングは、そのゲームの KP が **確定して入金されたときに1回だけ**（`relic:<元の記録ID>` で二重払いしない）。マイナスの結果には付かない。

| ゲーム | 対象額 | 「勝利・達成」扱い | 基準額（低 / 高） |
|---|---|---|---|
| 雀魂（`mahjong`） | 承認・自動確認されたプラスの KP | 1位 | 100 / 400 |
| ポケモンユナイト（`unite`） | 確定したプラスの KP | 勝利 | 100 / 400 |
| Steam実績（`steam`） | 実績ごとに入った KP（1日5,000の上限後） | 常に達成 | 100 / 500 |
| KESO LOOP（`loop`） | 到達報酬（1,000 / 50,000 / 300,000） | 常に達成 | 1,000 / 50,000 |
| デスマッチ一発勝負（`dmchallenge`） | 成功時の 5,000 | 成功 | 1,000 / 5,000 |

- スキルの種類は既存と同じ表（奇数・素数・25の倍数など）から各レアに割り当てた。全ゲーム共通（universal）・特殊条件（fortune）の遺物も、これらのゲームで効く。
- 遺物の上乗せには上限がない（V6 から）。KESO LOOP は元の額が大きいため、上乗せも大きくなる。
- おまかせ装備・ビルド診断・モード別プレビューに5ゲームを追加した。
