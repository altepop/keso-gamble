# KESO PLAY：Discordゲームセンター

## 使い方

- `/play`：6種類のゲームを選ぶ。ボタンを押すと、そのゲームの遊び方とActivityへのリンクが自分だけに表示される。
- `/duel opponent game stake`：対戦相手・ゲーム・1人分のKPを指定し、Discordのチャンネルに招待カードを投稿する。
- `/recruit game slots`：ゲームと参加予定人数を選び、参加募集カードを公開する。人数の指定を省略すると5人募集となる。

対応ゲーム：オセロ、五目並べ、四目並べ、Hit & Blow、ブラフダイス、簡易ポーカー。

## 決闘の招待

招待カードには「承諾」「辞退」ボタンが表示される。承諾できるのは指名された本人のみであり、依頼者は取り消しを選べる。招待は15分で期限切れとなる。

**KPは招待時点では引き落とされない。** 承諾時に双方の残高・借KPを検証し、既存の決闘システムで両者のKPを同時に預かる。試合が終了すると勝者に総額を支払う。引き分けでは各自の賭け金が戻る。対戦開始後はカードのActivityボタンを開き、「決闘」から試合を進める。

## リアクション参加受付

募集カードの **✅リアクション** を付けると参加、外すと退出となる。「✅ 参加する」「❌ 退出する」ボタンでも同じように操作できる。

- 主催者は投稿時に参加者へ自動登録される。
- 参加者は先着順で管理し、同じ人が複数回押しても1人として数える。
- 募集人数は2〜10人、募集は2時間で締め切る。
- 同時に募集中にできる投稿は主催者1人につき3件まで。
- **募集に参加するだけではKPは消費しない。** 対戦が必要になったら別途 `/duel` で招待する。

リアクション受付はBotの接続・チャンネル権限によって一時的に遅れる場合がある。その際はカードの参加ボタンを使う。投稿内容と参加者の状態がずれた場合は、一度参加・退出ボタンを押すと最新情報へ更新される。

## 運用上のルール

- 招待、決闘、募集の処理はサーバー側で行う。表示上のボタン操作だけではKPを変更しない。
- 招待できる相手はKP口座がある参加者に限定する。自分自身への招待はできない。
- Discordの操作IDを使った冪等処理により、再送による二重招待や二重精算を防止する。
- 募集データは期限付きで保存し、古いデータを定期的に削除する。
- 通常の投稿は全員宛メンションを発生させない。対戦招待のみ、指定された相手へ通知する。
- 追加のVALORANT戦績APIポーリングや独立したCronは設けない。
