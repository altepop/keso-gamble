# Steam限定遺物 7段階×30種 — 2026-11-05

KESO PLAYのSteam実績限定遺物を、既存の12系統に各解除率帯専用の18種類を追加して拡張した。世界解除率7帯、各30候補、合計210通り（うち126候補が新設）である。実績名が末尾に付くため、ゲーム・実績によって実際の所持品名はさらに変化する。

## 入手範囲と格付け

- 0%以上〜0.01%以下：異界
- 0.01%超〜0.1%以下：深淵
- 0.1%超〜1%以下：神話
- 1%超〜5%以下：偉業
- 5%超〜10%以下：熟練
- 10%超〜25%未満：挑戦
- **25%以上〜100%：旅路（入手可能）**

25%は「旅路」に分類される。25%未満も各上位グレードで入手可能だ。解除率が高いこと自体は抽選・受取の障害ではない。

## 強さの幅

同じグレードでも、誰でも使える低倍率・特定モード特化・高条件付き大倍率・トレードオフ型・連鎖専用・ほぼ収集用の低性能品を含む。最上位グレードだから全品最強とは限らず、「旅路」でも素数・末尾7・条件付きで強いアイテムがある。

- **異界**：常夜の永久機関（全ゲーム報酬＋420%、固定＋180KP）、千年を裂く羅針盤（素数KP時＋900%）、終焉の契約書（高額報酬＋1400%、不発時ほかの遺物のボーナス95%減）
- **深淵**：黒潮の動力核（全体＋245%、固定＋95KP）、写し身の獣面（他遺物の最大倍率分を140%複写）
- **神話**：神代の歯車（全体＋170%、固定＋55KP）、虹色の借用書（連鎖1個あたり＋80KP）
- **偉業**：達人の起動鍵（全体＋95%、固定＋24KP）、百人の拍手（通話＋145%、連鎖1個につき＋32KP）
- **熟練**：匠の計算尺（全体＋62%、固定＋15KP）、激流の契約紙（高額報酬＋350%、条件未達でほかの遺物－50%）
- **挑戦**：挑戦者の方位磁針（全体＋44%、固定＋10KP）、一攫千金の栞（素数KP＋260%）
- **旅路**：始まりの灯台（全体＋20%、固定＋6KP）、木製の秘密鍵（素数KP＋160%）、逆さの靴下（全体＋1%）

全件の正式なデータは `src/steam-relic-catalog.ts` に収録する。Activityの「記録 → Steam限定遺物 → 全候補を見る」からも確認できる。

## 固有能力

- **固定**：本来の倍率とは別に指定したKPを加算する。元報酬がプラスかつ対象の条件を満たしたときだけ発動する。
- **連鎖**：同時に発動したほかの装備遺物の個数だけ固定KPが増加する。単独では追加連鎖KPを得られない。
- **複写**：ほかの装備遺物が発動した倍率由来の追加KPの最大値を参照し、その指定割合を足す。連鎖の固定KPや他の複写を再帰的にコピーしない。
- **禁呪**：高倍率だが、自分の条件が未達の場合はほかの装備遺物の**追加KPだけ**を指定割合減らす。無関係なモードでは発動せず、元報酬も減額しない。
- **収集用**：あえて+1%や+2%などの弱い遺物も含む。全員が最強遺物を得るわけではない。

## 入手判定・保護

- 元の12系統は各グレードの候補に残る。遺物はゲームID・実績IDの決定的ハッシュにより30候補から決定し、クライアントが選ぶことはできない。引き直し・連打による変更はない。
- Steam Web APIとD1に残る、**監視開始後に検証・支給された実績**だけが請求可能。既存の受取済み遺物は保存された性能のまま維持し、再計算・再抽選しない。
- **当日のSteam KP上限5,000と限定遺物取得制御は変更しない。** 日上限で0KPになった実績は、翌日になっても限定遺物を請求できない。上限到達後は翌朝9時まで請求を停止する。
- 有料販売中・累計プレイ時間2時間以上の対象ゲームだけが報酬対象。過去の実績には遡及しない。
- Steam限定遺物の保有上限200個は現状維持する。Steam限定品の欠片化・転売不可も維持する。
- Steam実績を確認するためのD1クエリ増加や定期スキャンは**追加しない**。サーバー側の遺物図鑑表示は静的定義を返すだけである。

## 安全性と境界

倍率は確定した元報酬に対する上乗せであり、実績判定・元の報酬額・日次Steam基本報酬の5,000KP上限を変更しない。Steam限定遺物のボーナスは通常遺物と同様、合算上限なし（従来仕様）である。記録上は元報酬と追加KPを分ける。

既存の12種・既存受取品との互換性を重視し、今回の新設は未来の獲得にのみ適用する。
