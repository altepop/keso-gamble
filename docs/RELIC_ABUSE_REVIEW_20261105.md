# 遺物ボーナスの悪用一覧と対策（2026-11-05）

オーナー依頼：「株を売って買ってだけでも稼げちゃわない？悪用一覧を考えて、そのうえで修正」。
#335（カジノ全7種の上限）の続き。遺物そのものの倍率・所持・入手は変えず、**最終的な追加KP**だけを絞る。

## 共通の原則

遺物ボーナスが「利益」に掛かるモードでは、**実際に投じたKPに比例した上限**がないと、
期待値がマイナスの遊び方（手数料・控除のある売買や賭け）でも、遺物ボーナスで期待値がプラスに転じて無限に回せる。

上限 = `min(本来の遺物ボーナス, ceil(実際に投じたKP × 0.5%), 1回250KP, その日の残り)`、1日500KP（日本時間9:00区切り、モードごとに別枠）。

| モード | 「実際に投じたKP」 |
|---|---|
| カジノ（#335） | その勝負の実掛け金（複数番号・ダブルは合計） |
| 株（今回） | その売却の約定代金（手数料前の総額） |
| 競馬（今回） | その精算に含まれる全馬券の購入額の合計 |
| Mリーグ（今回） | その精算に含まれる全予想の購入額の合計 |

0.5% は株の往復手数料（買い1%＋売り1%）や賭けの控除率より小さいため、上限いっぱいでも回すほど損になる。

## 悪用一覧

### 対策した（このPR）

1. **株：自分の買いで株価を吊り上げて、古い株を売る**（最重要・再現済み）
   - 注文は株価を動かす。古い安い株を持った状態で大量に買って株価を上げ、先入れ先出しで古い株から売ると、
     「古い株の取得額 → 吊り上げた売値」の差が利益として数えられ、遺物ボーナスが付く。
     あとで新しい株を安く売った損は数えられない。
   - 例（初値1,000・古い株100株・2,000株で吊り上げ）：見かけの利益 **+191,050 KP**、実際の収支 **−80,000 KP**（手数料）。
     遺物ボーナスが利益の約42%を超えると、回すほどKPが増えた。
   - 対策後：この売却の遺物ボーナスは最大250 KP（1日500）。往復手数料の方が大きく、増えない（`test/native-relic-guard.test.ts`）。
2. **株：同じ株をまとめて買い、すぐに分けて売る**（古い株がなくても成立・オーナー指摘で再確認）
   - まとめて買うと取得単価は「平均」で記録されるが、直後の売値はまだ吊り上がったまま。最初の数回の売りは平均取得単価より高く売れて利益に数えられ、
     最後の方の売りの損は数えられない。双面の魔導銀貨（偶数の利益で+220%）などで遺物ボーナスだけが増える。
   - 例（初値1,000で1,000株買い、100株売る）：見かけの利益 **+41,550 KP**。双面の魔導銀貨＋暴走する鎖の心臓での総当たりでは、
     上限なしだと実際の収支 −255万 KP に対し遺物ボーナス **+5,846万 KP**。上限後は最良でも **−120 KP**（全パターンで損）。
3. **株：仲間に買い上げてもらってから売る（共謀）**：1と同じ仕組み。同じ上限で止まる。
4. **株：1回・1日の上限がない**：大口の通常の値上がり益にも青天井で掛かっていた。上限を追加。
5. **競馬：高倍率・大口の当たりに青天井**：遺物ボーナスで賭けの期待値がプラスになる構成があり得た。精算の購入額合計で上限。
6. **Mリーグの予想**：5と同じ。

### 対策済み（#335・#336）

7. **カジノ全7種**：ルーレットの35/37点買いなど、ほぼ確実な小さな勝ちに大きな遺物ボーナス。実掛け金で上限。

### 確認して問題なし

- **同じ株を同じ数量で一度に買って一度に売る**：平均取得単価と平均売値が同じになり、手数料ぶん損で利益に数えられない（ただし分けて売ると上の2になる）。
- **競馬・Mリーグの全通り買い**：同じ精算の純利益で判定するので0。
- **遺物の分解→欠片→交換の繰り返し**：分解で得る欠片（通常1・採掘遺物で+1）が交換に必要な欠片（通常15）より少なく、増殖しない。
- **遺物マーケット・KPの譲渡**：プレイヤー間の移動で、KPは増えない（遺物ボーナスの対象外）。
- **VALORANT・スカーミッシュ・デスマッチ一発勝負・通話・Steam・雀魂・QUIZ・LOOP**：
  実際の試合・検証済みの記録が元で、回数も試合時間・1日1回などで限られる。

### 残ること（今回は変えない）

- 共謀による株での**実際のKPの受け渡し**（Aが得てBが損）は、譲渡と同じでKPは増えないため対象外。
- 画面の「装備効果は上限なしで合算する」は遺物の計算の説明として正しいが、
  **カジノ・株・競馬・Mリーグでは実際の支給に上限がある**ことを画面にも書くとよい（別PRで検討）。
