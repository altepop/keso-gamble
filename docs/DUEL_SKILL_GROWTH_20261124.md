# 決闘熟練度の成長速度調整（P11/P12、2026-11-24）

## 適用範囲
サーバーが確定した**自然終局**の受領だけが対象。ブラウザ練習、投了、時間切れ、破棄、取消し、試合結果の手入力では熟練度は発生しない。

| モード | CPU難易度 | 勝利 | 敗北 | 引き分け |
|---|---|---:|---:|---:|
| PvE | かんたん | +8 | 0 | +2 |
| PvE | ふつう | +12 | 0 | +3 |
| PvE | つよい | +16 | 0 | +4 |
| PvP | 対人戦 | +14 | 0 | +4 |

難易度はクライアント申告ではなく、確定済み `kp_duel_pve_sessions.difficulty` を受領に対応付けて使用する。対応する所有者・guild・種目のサーバーセッションが見つからなければ熟練度を発行しない。

## 成長ペース
同じ種目とモードに10勝すると、PvEかんたん+80、ふつう+120、つよい+160、PvP+140。勝率50%、引き分けなしの10戦なら、それぞれ+40、+60、+80、+70が目安となる（負けは0）。同じ10試合でも異なる種目・モードの点数は合算せず別管理。

熟練度の最小は0で、DDLには最大値・ランク段階境界はない。上限・段階境界を変更する必要はなく、新しいランクや称号を架空に追加しない。既存の `points` と `peak_points` を保持し、最高到達点も累積成長に追従する。

## 安全性・既存記録
新しい加点は**変更後に発行される受領のみ**。既存の1勝1ptで確定した行を一括変換・バックフィルしない。現行の一意キーとトランザクション境界、本人認証、PvE/PvP別・種目別レコード、戦績カウンタは維持する。

リワードの `daily_cap` / `pair_cap` は抽選ロール `kp_duel_reward_rolls` の制限であって、熟練度の上限ではない。熟練度への日次上限・相手別上限は現状なく、今回も新設しない。反復プレイに伴う無制限な熟練度増加は仕様上あり得るが、KP・遺物の付与確率や上限は別制御のまま据え置く。

既存トリガーはD1の単一トランザクション `batch` で交換する。試合終了と受領・熟練度は既存の原子性を維持し、過去受領を再処理しない。
